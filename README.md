# 原子工坊 · Atom Atelier

一个中文 3D 科学经营小游戏 Demo：点击积累金币，在可延伸的小岛摆放反应炉，调整炉内原子，收获、开箱、招募伙伴，再发现下一种结构。

## 开始试玩

**双击 `START_DEMO.cmd`。** 已附带官方 Godot 4.7.2 便携运行环境，无需另外安装 Godot，也无需联网。

- `OPEN_EDITOR.cmd`：打开 Godot 工程继续开发。
- `launch_demo.ps1`：优先通过 PowerShell 7 启动；批处理在缺少7时兼容 Windows PowerShell。
- 进度每20秒、操作后及正常退出时保存在项目 `saves/save.json`；上一份存档保留为 `.bak`。
- Windows 版的环境、存档、截图、缓存和临时文件都保存在本项目内。未启用云服务、支付或真实计算服务。
- 建议1440×900窗口；最低1152×720，界面等比例缩放。

## Android 试玩

安装包：[AtomAtelier-0.10.0-android.apk](builds/AtomAtelier-0.10.0-android.apk)，约69 MB。支持 Android 7.0 及以上（API 24）、ARM64 / ARMv7 手机，横屏触屏操作；原子工作台提供旋转、俯仰和缩放按钮。手机存档保存在应用私有目录，切到后台时自动保存。

这是使用测试版签名的 Demo。已通过 APK 签名、包内资源检查及桌面触屏仿真；**尚未进行 Android 真机测试**。

在项目目录用 PowerShell 7 运行 `./build_android.ps1` 可本地重新构建。下载的工具位于 `tools/`，构建缓存位于 `.runtime/`，输出位于 `builds/`；开发工具与缓存均保留在本项目内。

## 0.10 浮岛焕新

HCl识别不再依赖起始模板；旧版误标库存会保留数量修正身份。长按建筑约半秒，拖到绿色空地松手放置，红色位置或移出地图取消。底部「建造 / 公园」直接选择空地，公园列在前面。

院士别墅、教授公寓、博士宿舍、公园采用不同模型。广场外围步道保持邻接连通；静态几何合批、拖动镜头后延迟更新细节、覆盖面板时暂停岛屿绘制，Web使用更轻的显示预算。详见[0.10版本说明](docs/V0.10.md)。

地球尚未实装。[详细设计方案](docs/EARTH-DESIGN.md)和[独立核心评审](docs/reviews/EARTH-CORE-REVIEW.md)说明材料用途、人员分工、首个水循环切片、数值与建模预算；多名子代理联合评审仍需完成。

## 0.9 浮岛日常

这一版新增分类工具箱、待领取与满仓暂停、博士实际装炉/收集、公寓泡面与可乐补给、广场邮箱及最多三位独立采购商、可拾取的3D庭院收藏。替换元素不再作为院士课题，团队研发转向缓冲仓和工艺改进。详细规则见[0.9版本说明](docs/V0.9.md)。

广场邮箱查看订单；来客亮气泡可直接交付，灰气泡查看需求。底部「工具箱」购买补给并放入博士公寓；满仓时可随时手动收获。换元素预付一次费用，等待博士步行装炉，可取消退款；旧批次保留。

下一章节的[研发与模拟地球方案](docs/PLAN-RESEARCH-PLANET.md)已记录工业产品层、限定适用范围的物性估计和区域化星球视觉演化。当前尚未实现地球、工业管线或真实多物性预测。

## 保留的科研小镇玩法

底部「科研小镇」是新入口：建连通道路、住宅、院所、食堂和公园，查看每位居民的性格、行程、薪酬与心愿。工程师到岗施工，收购商骑车或乘车来广场；一块地可以同时有主建筑和8件庭院物件。

博士生45金币招募、每天4金币津贴，可以独立开展基础课题。每名院士同时主持1个进阶课题；教授是可选导师，提升所带博士生的研发效率。全部角色都有招募费和持续薪酬，键长仍由玩家调整。具体数值、玩法边界与配置文件见 [0.8版本说明](docs/V0.8.md)。

本机浏览器试玩：[打开游戏](http://127.0.0.1:8765/)。需保持项目内的预览服务运行；浏览器存档与Windows版独立。

## 0.7 保留的玩法

0.7 将结构工作台真正接入反应炉：增删/替换原子、编辑键级、保存命名作品、正交晶胞重复预览、科学/艺术模式。14种基础结构用于生产与收藏；未识别作品可出售给每四位一轮的创意收购商。

收购商是会走入、挥手、离开的3D角色；0.9起按独立来访间隔与停留时间调度，最多3位。报价随已收集批次排序。建筑免费搬迁，道路、围栏可购买；完成3次交付解锁原子雕塑。

研究站执行小型数值计算并显示结果曲线：H–O/H–C/有限离子单元的人工弹簧势、H₂人工数据核回归、两电子一维软库仑Kohn–Sham模型。**一维模型不是实际三维分子DFT**。计算免费，优化结果单独确认应用并收取固定编辑费。模型、适用范围与独立数值校验见 [科研说明](docs/SCIENCE-V0.7.md)。

## 前五分钟

1. 选中中央的水分子反应炉，点击“进入原子工作台”。拖动球体或使用X/Y/Z微调按钮，观察产率。
2. 右键拖动旋转结构，滚轮缩放；确认应用时扣费，取消不扣费。Lv.1每次确认12金币，同等级价格固定。
3. **编辑或装炉前保存旧批次和金币。** 换元素或配方等待博士装炉，坐标调整即时生效。
4. 点击“注入微光”每次+2金币，点击“收获全部”领取反应炉积累的金币及建材。已完成产物用于订单。
5. 首个探索箱免费。金币箱可能开出金币、建材或工程师，每第10箱获得伙伴奖励；缺少空床位时折为85金币。
6. 点击空地建新炉、晶体花园或工程师小屋。点击锁定地块，用星砂、晶露、合金片开拓相邻土地；初始格各2份，远处更多，当前可开拓128格。
7. 广场邮箱和来客气泡收购3份已入库产物；类型相符且几何响应接近目标，奖励精品催化晶，用来升级炉子。
8. 建科研院所、博士公寓并连路，招募科研人员；团队研发解锁工艺能力，研究站继续提供限定体系的教学计算。
9. 打开元素仓库购买原料，在工作台替换元素。试试O→S；预览、撤销和取消免费，应用时扣库存及一次编辑费。
10. 打开“结构工坊”，从 14种基线复制作品，或从空白增添原子。保存后可应用到选中的炉子。

## 科学边界与后续章节

金币响应是游戏中的几何评分，不是真实能量、稳定性或带隙预测。已知分子按元素、连接关系、键级匹配参考，重排原子编号仍可识别；未识别结构保留探索身份。LiF/NaCl为CN6离子半径之和的展示对，不是气相分子平衡键长。钙钛矿为理想示意晶胞，不是室温实验相。

模板/半径/参考来源在 `data/materials.json`、`data/elements.json` 与 `data/baselines.json`；金币基础公式在 `data/economy.json`；生产周期、仓容量、掉落、补给和来访节奏在 `data/island_balance.json`。只有已有参考可评精品，创意交易不产生精品催化晶。探索样品的收获不掉落科研建材。

周期晶胞现在提供几何编辑与2×2×2预览，尚无周期能量计算。表面、缺陷、大分子、高聚物、真实物性订单、外部三维DFT仍留待后续版本。人物和设备由程序化几何制作，Blender不是运行依赖。
