# 0.1 设计存档：玩法与经济规则

> 本页保留首版设计，现已发布0.2。地块、收益、买家价格与存档规则以 [0.2版规则](V0.2.md) 为准；整体计划见 [ROADMAP](ROADMAP.md)。

本演示把「点击、收集、建设、原子编辑」连成一个短循环。玩家在小岛的格子上建造反应炉，调整炉内结构，收获金币和建材，完成买家订单，再扩大岛屿、升级设备和招募团队。当前已经实现的内容以 `scripts/lab_state.gd` 与 `data/materials.json` 为准；以下所有价格、分数和概率都是游戏数值。

## 一局如何开始

开局有220金币、星砂/晶露/合金片各2份、1位工程师。岛屿是3×3共9格，中间一排及下方中间格已开放；中央放着一台Lv.1水分子反应炉。初始水分子的两个原子稍微偏离参考位置，方便玩家观察编辑前后的产出变化。

推荐的首轮体验：

1. 点击聚能，每次获得2金币；观察炉内产物自动积累。
2. 打开原子编辑器，选中原子调整坐标，预览参考几何匹配度，再确认一批调整。
3. 收获待领金币和随机建材；产物库存用于买家订单。
4. 将高匹配度水分子交付给第一位买家，得到金币和精品催化晶。
5. 用催化晶升级反应炉，或花100金币在空地建第二台炉。
6. 开一次免费探索箱，招募工程师，加速建设；三类建材用于继续开地。
7. 花园、居所与不同模板的反应炉组成自己的小岛。

## 点击、生产与收获

点击直接增加金币，自动生产所得金币先留在反应炉，点击单炉收获或全部收获后进入钱包。产物完成一个生产周期后进入库存，买家可直接取走；收获负责结算金币和相应批次的建材掉落，不会把库存清零。

设炉子等级为 `L`，参考几何匹配度为 `q`（0至1）：

- 待收金币增长速度：`模板基础速率 × (0.15 + 0.85q) × [1 + 0.45(L−1)]` 金币/秒。
- 产物生产速度：`(0.35 + 0.65q) × [1 + 0.35(L−1)] / 7` 份/秒。
- 满匹配度的Lv.1炉约每7秒完成1份产物。
- 基础速率：H₂为1.2，H₂O为1.6，CH₄为2.4，CsPbBr₃教学晶胞为4.0。

这些速度只为试玩节奏设计，不表示实验反应速率或材料价值。当前没有离线收益计算：程序关闭后不会自动累计产物。

## 土地、装饰和工程师

| 项目 | 当前规则 |
| --- | --- |
| 开拓一格 | 星砂、晶露、合金片各2份；没有额外金币费用 |
| 新反应炉 | 100金币，占用一格已开放空地 |
| 基础建造量 | 12秒工程量，建造期间不生产 |
| 工程师加速 | 建造速度为 `1 + 0.55 × (工程师人数−1)` |
| 招募工程师 | `70 + 30 × (现有人数−1)` 金币，上限100人 |
| 花园 | 35金币，占用一格空地 |
| 居所 | 60金币，占用一格空地 |

本版装饰用于DIY，没有暗藏产能加成，也没有住房容量限制。建造后暂不支持搬迁、拆除和退款。购买土地暂不要求与现有地块相邻，最多开放9格。

每份已完成产物在收获时有38%概率掉落1份随机建材。连续未掉落时，第5份必掉1份，并优先补充当前数量最少的建材；掉落后重置计数。这个计数在所有反应炉之间共用，并写入存档。批量收获会逐份结算，反复点击空收获不能重复抽奖。

## 原子编辑与升级

编辑器支持已有模板内的原子位置调整，坐标单位为Å。当前不支持增删原子、改变元素种类、自动识别任意分子或自动重新判断成键拓扑。

每次确认一批有效且发生变化的坐标，费用固定为 `12 × L²` 金币。例如Lv.1每次12金币，Lv.2每次48金币；同等级下编辑次数再多也不会涨价。取消、无变化、无效坐标、金币不足时均不扣费。每个坐标分量限制在−20至20Å。

更换结构模板固定25金币；选择已经使用的模板不收费。编辑或换模板成功后会清空该炉的旧库存、待领金币、待结算建材批次与当前生产进度，以免把旧产物直接变成新结构。界面应在确认之前明确告知，建议文案：

> 确认后将扣除本次费用，并清空该炉旧库存、待收金币与生产进度；建议先收获并交付旧产物。

反应炉从Lv.L升到下一等级需要 `90 × L²` 金币和1枚精品催化晶，最高Lv.20。升级保留已有产物，提高生产速度，并改变此后编辑的固定费用。

每台炉有自己的实例编号；结构指纹由模板ID与坐标生成。同一模板但不同摆法会有不同指纹，相同坐标会得到相同指纹。它用于追踪一台炉里的结构版本，不是晶体学去重工具，也不保证旋转、平移或相同元素交换后仍保持指纹。

## 买家订单与精品

买家按水分子、甲烷、氢分子、钙钛矿教学晶胞的顺序轮换。每单需要3份库存，目标匹配度为98%，四类订单的精品金币奖励依次为85、100、115、130。

只有「模板类型相符，并且匹配度与98%的差值不超过5个百分点」才算精品。当前分数上限为100%，因此93%至100%的同类结构满足精品条件；这里的5个百分点不是相对误差5%。精品额外奖励1枚催化晶，用于升级反应炉。

玩家可以交付非精品或其他模板，买家仍会按接近程度普通成交，但金币减少且没有催化晶。普通成交系数为 `max(0.25, 1−匹配度差值)`，再乘同类0.75或异类0.40，取整且至少15金币。每次成交都消耗3份库存并推进订单；没有库存时不能成交。所谓匹配度不是导电率、带隙、能量或任何未计算的材料物性。

## 探索箱

探索箱只能用本地游戏金币开启，本版没有支付功能。

| 结果 | 普通箱概率 | 奖励 |
| --- | --- | --- |
| 金币 | 50% | 28至90金币，整数等概率 |
| 建材 | 35% | 三类中随机一种+3 |
| 工程师 | 15% | 工程师+1 |

首箱免费，其后每箱45金币。总开启次数达到10、20、30……时，该箱必得工程师；普通箱提前获得工程师不会重置这个固定里程碑。第10箱的实际工程师概率为100%，不使用普通概率表。工程师达到100人时，工程师奖励改为100金币。概率与保底文案保存在材料数据库，供界面展示。

## 研究、图鉴和后续章节

拥有至少2位工程师后，可花100金币让科学家入驻，解锁水分子的H–O参考几何辅助。辅助会把坐标恢复到数据库模板，并使用同样的编辑扣费与清库存规则；它不会运行真实势函数，也不能辅助其他体系。

开局解锁水分子图鉴，其余模板在首次有产物收获或成功交付后进入图鉴。当前共4个模板，分为分子和晶体两类。表面、缺陷、大分子、高聚物、玩家自由增删原子、任务活动和稀有装饰属于下一阶段，尚未实现。

后续先用Blender制作风格统一的反应炉、工程师、科学家、植被和建筑，导出glTF/GLB供Godot调用；原子球、键、晶胞边框仍程序化生成。真实势函数按元素体系、适用条件和版本分别解锁。机器学习势与DFT应接独立计算任务，显示单位、方法、收敛状态和适用范围，保留轻量几何玩法作为即时预览。

## 存档和验证

存档位于当前项目的 `saves/save.json`。保存先写临时文件并保留旧存档备份，再替换主文件。读取校验金币上下限、整数库存、地块归属、模板、原子数量和有限坐标；主文件损坏时尝试备份，两者都无效则保持当前游戏状态。不会把存档写到用户文档或系统目录。

`tests/test_state.gd`已通过44项无界面检查，覆盖参考几何、碰撞惩罚、坐标不变免扣费、同级恒定编辑费、升级价格、工程师加速、库存扣除、改结构清库存、掉落与盲盒保底、体系研究限制、存档往返与损坏恢复。这是经济与数据层验证，不代替画面和实际交互验收。
