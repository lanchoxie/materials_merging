# 地球章节独立审视：材料研发如何真正改变一个世界

审视日期：2026-09-19。本文是方案与验收建议，不代表功能已经实现。审视范围包括现有地球计划、人员研发、样品库存、订单和教学计算代码。

## 1. 核心判断

建议把地球做成“用自己研发的产品解决区域问题”的可视化试验场。玩家最有价值的动作是提出用途、比较候选、安排验证、选择工业配方和部署位置。换一个原子只是提出一个候选；院士不能靠等待替它盖上“研发成功”的章。

完整循环为：

**看见区域的问题 → 决定需要什么产品 → 选择样品与适用方法 → 博士完成实验 → 玩家比较结果并调整结构 → 教授形成可复用工艺 → 工程师生产、运输和安装 → 地表发生可见变化 → 产生新需求。**

第一版应证明这条循环能走通。不要先制作很多时代、恐龙和城市，再用“投入 100 材料升级时代”把它们串起来；那会让材料沙盒变成换皮资源桶。

## 2. 现有设计中需要直接修正的地方

|现状|隐患|建议|
|`quality()` 是参考键长、键角及几何匹配度|把它直接当净水率、产电效率，会把游戏评分伪装成物性|保留“参考几何匹配”原名。它影响样品验收和游戏产速；应用性能读取独立证据记录|
|现有科研课题主要是花钱、配人、等待解锁|更换元素之后再等待一次，缺少科研决策|永久能力研究与可重复的样品试验分成两种任务；试验需要候选、方法、条件、对照及用途|
|教授目前主要给博士增加 50% 工作速度|4 名博士得到的增量约为 2 名博士，但教授日薪 24、博士日薪 4；玩家很容易觉得教授只是昂贵门票|教授的独有收益应是实验方案、对照检查、批次复现和工艺窗口，速度提升只是附加收益|
|院士解锁更多并行高级课题|若所有高级课题都是多招博士也能做的重复计时，身份没有意义|院士负责方法适用范围、新结构族和跨区域长期难题；并行数同时受仪器与预算约束|
|已知参考以外的样品通常没有几何分数|如果后续应用都要求分数，创造新材料就等于自我惩罚|“未知”成为研究入口；暂不能用于有性能承诺的订单，但保留试验、展示、委托研究和外观设计用途|
|`CampusSim` 的课题按项目 ID 去重，完成后永久解锁|不适合承载同一方法对许多样品重复测试|新增独立 `ExperimentJobs`，不要把样品指纹拼成几千个永久科技节点|
|目前只有样品包，没有工业质量、能量和产品批次|直接把一个分子拖成一片海洋，视觉上爽快但逻辑断裂|增加配方与产品层；先用“标准水箱/组件包”的游戏计量，后续有物料衡算再引入 kg、L 等真实单位|

当前教学计算已经明确标注人工弹簧势、人工 Morse 数据和一维双阱模型。这是应保留的优点。它们可以帮助理解优化与模型验证，不能充当地球能源、净水和真实材料稳定性的通用预测器。

## 3. 让四种人员各有决定性的工作

|人员|常规工作|研究中的独有作用|玩家做的选择|不应该自动替玩家完成的事|
|---|---|---|---|---|
|工程师|施工、维护、运输、接通管线|把通过验收的配方放大为生产线；处理吞吐、能耗、设备维护|线路、工厂位置、产能分配、生产优先级|自动发明材料、凭维护次数改变物性|
|博士|装炉、收集、补给、采样|运行已解锁方法，重复测试，整理对照；一次只能占用一个实际岗位|收集与试验之间如何分配，谁测试哪个样品|自动修改玩家原子坐标、把未知结果编成已知|
|教授|指导小组、制定试验和工艺|开启一套实验方案，建立条件对照、批次复现和可生产工艺窗口|少量快筛还是完整复验；提高产量还是降低返工|凭头衔消除模型误差，给所有材料统一加“科研质量”|
|院士|主持长期课题|新测试能力、结构族探索、模型适用范围拓展、长期区域难题|扩展哪个体系、投入哪些训练与验证样品、哪条应用路线值得开拓|给一个元素替换做审批；无条件预测任意物性|

教授可以将“4 个博士轮流手工跑同一实验”变成“一组对照与候选并行比较”；院士可以让原来根本不能评估的材料族进入可评估范围。这两个差别都比单纯减时间更有辨识度。

第一批地球任务不能要求玩家先买齐四种人。现有博士可以完成已知水样的装炉、收集；已有工程师可以生产和部署标准产品。教授在第二条工艺路线出现，院士在第一次方法扩展出现。已有高级人员则有额外方案可选，不成为入门门票。

性格改变工作节奏、偏好与请求，不悄悄改变科学真值。例如爱散步的博士获得灵感事件或更喜欢公园，但实验记录仍注明同一方法；认真程度可影响需要补做的操作步骤，不能随机把真实带隙改大。补给停工要提前冒泡，给玩家转人工收集与调整岗位的机会。

## 4. 科技树研究的是“以后我能做什么”

建议四条短而相互交叉的能力线，每个节点至少新增一个玩家动作或一个明确取舍。

|能力线|前期节点|新增决策|未来节点|
|---|---|---|---|
|看得清|参考对照、结构族筛选、测试条件设置|挑选两个候选，在同一条件下比较|多性质筛选、适用范围可视化|
|做得稳|缓冲仓、批次复验、工艺窗口|产速与返工风险如何权衡|连续生产、工艺迁移|
|造得多|标准装罐、模块封装、回收循环|输出卖给采购商还是部署地球|气体管线、能源与水循环工厂|
|想得新|候选结构族、模型训练与验证|在哪个体系继续投入证据，何时停止投入|有范围的机器学习势、外部真实计算导入|

“结构族探索”给出数个有出处或明确假设的候选方向，不直接生成一个被宣称最稳定的新晶体。玩家可以保留自己的候选并继续调整；课题的产物是能力、候选与证据，而不是一个永远盖章的材料名字。

失败也应该留下有限而具体的东西：排除一个条件范围、知道某模型不覆盖该体系、记录一次工艺不匹配。不能每次失败都免费发万能研究点，否则最佳策略会变成刷失败。

## 5. 订单应提出问题，并给玩家多条可行路径

名称订单保留作初学关卡。地球引入的是“应用合同”：对象、条件、需求区间、预算、需要维持的时间和可接受代价。

例子（均为未来设计，性能数据接入后才能启用）：

- 海湾：在给定污染物与水况下完成一次处理任务。比较净化效率、耗材和能量，而不是要求一种固定分子。
- 岛上观测站：在固定光照场景下维持照明。可以选择更大面积的标准组件，或经过验证的新组件；不能只看吸收层带隙就算整机发电。
- 远方聚落：在给定条件下提供一批耐用构件。便宜但需要常维护，与昂贵但寿命长，都能形成可行解。

精品应表示“有证据地满足约定”，而不是“所有数值越高越好”。需求是区间时，超过上限未必更好。替代品可以改成试用合同：明确缩小覆盖范围或缩短承诺时间，奖励随履约范围变化；不冒充原要求已经完成。

## 6. 新材料的自由度：四种证据状态，而非一个真假开关

|状态|画面上可说什么|可以做什么|不能做什么|
|---|---|---|---|
|参考已知|“参考数据；条件为……”|匹配条件的试验、订单、产品配方|把另一晶相或另一条件的数据直接借过来|
|范围内估计|“估计区间；适用于……”|小批试用、保守验收、比较候选|把插值当测量值；越过训练范围继续外推|
|方法支持、待测试|“这套方法可以评估；尚未测试”|安排试验，得到计算记录或有范围的教学结果|只因交了研究费就标成优秀材料|
|当前无依据|“性质未知”|保存、命名、展示、提交委托、加入未来方法的候选清单、生成地球纪念雕塑或外观纹样|凭原子半径、原子数量或随机数生成真实净水率、硬度、带隙|

必须接受一个设计事实：任意原子组合与真实全物性预测，不可能靠一个便宜通用公式同时满足。把所有未知材料都赋予五维“能力值”虽然方便，会削弱本项目最有吸引力的科学性。

未知材料仍可立刻影响星球的外观：它的原子构图可以被放大为观测站纪念装置、雕塑或装饰图案。若使用一个已有认证的标准组件，玩家自创结构只改变装饰外观，则产品性能完全来自标准组件，不声称新装饰材料有某种强度或效率。这样保留创作回报，又不伪造未知物性。

另设可选“幻想沙盘”时，允许用明确标为游戏规则的材料特征影响地表表现；其结果必须与科学档案分开，不能写回真实属性，更不能作为科学订单的精品证据。第一版无需同时做这个模式。

## 7. 插值可成为玩法，但前提必须写进规则

只在同一材料族、相结构、条件与属性定义下使用一套经过验证的插值器。端点、中间验证点、有效范围和误差作为模型卡。玩家在范围内提出新组分，可以先拿到估计区间；补充测试缩小区间，才有资格签更严格的应用合同。

“离端点越近就一定越可信”也不能写成通用真理；置信区间来自所选模型的验证规则。跨相变、跨材料族、缺失关键条件时返回未知，并解释还缺什么。已有参考几何的高匹配度不等于这个插值器适用。

Materials Project 的电子结构文档说明，常见 DFT 方法的带隙存在系统偏差，计算与解析设置也影响结果。因此“解锁 DFT”不能成为无误差的终极鉴定按钮。[官方电子结构说明](https://docs.materialsproject.org/methodology/materials-methodology/electronic-structure)

NIST 的材料数据评价工作区分不同类型的关系、估计与依赖测试过程的数据，强调可靠性、完整性和一致性。本项目对应的设计选择是：每条属性带上来源、方法与条件，未知保留未知。[NIST 材料性质数据评价](https://www.nist.gov/publications/data-evaluation-theory-and-practice-materials-properties)

## 8. 首个可落地切片：为冷却盆地送去第一箱水

### 场景与边界

一颗可转动的熔岩风格星球，只有一个“已经冷却的封闭试验盆地”可操作。先做干燥盆地、浅水、循环运行三种可见状态。整体熔岩亮度与盆地演出是章节表达，不声称倒一箱水就完成真实行星冷却。首版不生成生命，不进化恐龙，不模拟全球气候。

复用已有水模板、样品批次、博士收集、工程师和工具箱。新增一个标准装罐配方、一种标准水箱、一个轻量生产任务和一个区域部署任务。装罐可先使用已有设施的附属设备；不为一个配方强迫玩家再建四栋新建筑。

最低应有一个真实选择：用同样的标准水箱，在盆地的两个落点中选其一。落在较窄深槽形成较集中水面，落在浅台形成较广而浅的水面，影响后续可摆设施的位置；这是基于预设区域容量和几何的游戏规则，不假装计算实际地质渗流。第一版只做一个落点也可验证技术链，但不足以验证沙盒趣味，应在下一次迭代优先补上第二种空间选择。

### 从已解锁地球入口开始的 5 分钟行动链

|时间|玩家动作|可见反馈|后台真正发生的事|
|---|---|---|---|
|0:00–0:30|点击邮箱里的观察站来信，旋转星球看干燥盆地|盆地轮廓和停转的循环泵；一张简短需求卡|生成唯一首次合同，不反复随机刷同一引导|
|0:30–1:00|回到浮岛选已有水批次；不足时把一个反应炉安排为水样|原子样品与装炉/收集路径连起来|复用已有样品队列；几何匹配影响样品生产，不被叫作水纯度|
|1:00–2:00|收集样品，选择标准装罐配方|工程师到设备旁；透明水箱逐渐装满|锁定输入批次与费用；完成后输出一个独立产品批次|
|2:00–2:30|在工具箱“工业产品”中按住水箱拖到盆地|有效落点高亮，预览影响范围和耗用数量|生成可取消部署准备，不因拖过区域就扣物品|
|2:30–3:30|释放并完成首次部署|小运输器抵达，水沿沟槽展开，泵开始转动|产品只扣一次；项目分阶段推进并保存|
|3:30–4:30|拖动观察视角、看前后对比，选择下一批供给还是出售|湿润地表与水面高光，浮岛订单仍在进行|奖励一次性；余量留在产品库存；重复部署受区域容量约束|
|4:30–5:00|打开结果卡，选择“改进循环”后续课题|问题从“缺水”转为“怎样少用补给”|教授工艺线第一次有用途；不会自动把整个星球升级一个时代|

这 5 分钟是具备基础人员与少量库存后的体验目标，不要求从新存档五分钟内攒出昂贵科研团队。引导可以赠送首次合同的装罐券或一份标准供料，必须记账且仅发一次，不能永久免费产水。

### 首轮工艺规则

- 配方必须列出所需样品包、标准供料、金币与时间；输入在开始时预留，取消按已定义规则返还，完成只写入一次输出。
- 样品包代表游戏内实验与规模化配方资格，不能把包数标成真实分子数量。首版产品单位为“标准水箱”，不显示未经物料衡算的吨数。
- 不符合配方的 HCl、NaCl 或任意含氧分子不能被自动当成水。界面显示“这份样品不是该配方所需水样”，保留原批次。
- 差一点的参考几何可以生产得慢，或者需要重新装炉；不要把拉歪的 H₂O 自动解释为有毒或不纯的水。
- 在这条切片上不应为了展示“材料差异”，硬编出未知材料与已知水的不同净化效果。首版比较的是合法原料与不适用原料、部署位置和工艺选择。两种具有真实不同性能的材料对照，应等数据和模型准备好后作为下一条切片验收。

## 9. 紧接着最值得做的第二条链

选择一个有可核对数据、范围狭窄的材料族与一个应用属性，而不是同时开放全部材料、全部性质。具体材料族应由可获得数据与许可决定，不在缺数据时先承诺一种“万能钙钛矿插值”。

第二条链应让玩家面对“两个候选都能用，但条件不同”：例如一个低成本标准组件与一个经过限定条件验证的新组件。在同一试验区布置两份产品，看到运行、维护或覆盖的区别，结果进入材料档案。教授负责比较试验，院士解锁下一段适用范围。这个回路成立后再扩成净水、能源、工业三类产品。

## 10. 数据与代码边界建议

保持五个记录分离：

1. `SpecimenRecord`：组成、坐标、连接、周期信息、规范化结构指纹。与从哪个模板改来无关；源模板只做历史记录。
2. `PropertyEvidence`：属性、数值或区间、单位、条件、来源、方法版本、适用范围、证据类别。游戏几何分数不进入此表。
3. `ExperimentJob`：样品快照、方法、条件、人员、对照、进度、结果状态。结构变化不能静默复用旧结果。
4. `ProductBatch`：配方版本、输入批次、数量、验收记录及可用场景。不同质量和证据条件的批次不能盲目合并。
5. `RegionProject`：目标区域、产品预留、部署位置、阶段、累计消耗与已经发放的奖励。

物性服务只回答“有何证据、是否在范围内”；配方服务回答“是否能生产”；区域规则回答“产品怎样影响这个游戏场景”。它们都不直接创建模型或按钮。3D 层只读取快照与事件，用户拖拽发出命令，由状态层统一验库存、扣费、保存。

现有 `science_runs` 有样品签名校验，这是可复用的思路；现有 `quality`、订单报价和库存 ID 不应同时承担物性有效性判断。规范指纹用于一致性，历史指纹迁移时保留旧批次的来源记录，避免修复 HCl 识别后丢货或把不同坐标批次错误合并。

## 11. 开发前后的验收清单

- 同一结构无论由哪个模板替换、以什么原子序号输入，都得到一致的参考识别；不同连接、晶相、周期属性不会因此合并。
- 原样品保存后修改反应炉，已装罐产品的证据与数量不改变。
- 反复拖入、移出、取消、双击、存档重开，不会重复扣产品、重复生成产品或重复领奖。
- 未知材料没有性能记录时，无法通过真实属性订单；仍能被保存、展示，并看到下一步可做的研究。
- 教学计算结果不会被地球配方当作真实的净水、带隙或强度数据。
- 第一次地球任务不用新增昂贵院士阵容；玩家能理解为什么生产、为什么测试、为什么不适用。
- 第一片水面一定来自已完成的产品部署，而不是打开地球页面就自动变色。
- 返回浮岛继续沿用现有生产和人员逻辑；两处画面只渲染当前所在场景，离屏推进保留状态。
- 试玩者在五分钟后能说出一个选择：“我把哪一批什么产品放在了哪里，为什么这样做”，而不只是“又等完了一根进度条”。
