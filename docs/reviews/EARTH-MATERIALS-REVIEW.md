# 地球章节独立评审：材料、配方与多重用途

评审日期：2026-09-19。本文是开发建议，未实现游戏功能。核对了现有地球设计、核心评审、元素与材料数据库，以及文末官方资料。

## 1. 我的核心建议

材料不能只有“好坏分数”，应具有带条件的多种性质；产品把这些性质变成可使用的能力，环境决定能力的后果。
同一种材料应有至少两种用途和一种代价，才能形成选择，而不是每发现一个分子便解锁一个固定收钱建筑。
建议采用 **材料证据 → 工艺与组件 → 产品能力 → 当地环境 → 生物或居民决策 → 可见反馈** 六层结构。
例如铜不会直接增加文明值；它先成为导线或换热部件，居民才能在已有设备与知识下改善供电或冷却。
科技解锁的是处理材料的方法、可制造的组件和可验证的条件，不是把所有材料的数值统一提高百分之十。

## 2. 当前项目能复用什么

目前有 12 种元素 H、O、C、Cs、Pb、Br、S、Cl、N、F、Li、Na，以及 14 种结构模板。
水、氢气、氧气、氮气、甲烷、二氧化碳、氨、NaCl 等可以提供早期题材；现有 Cu、Al、Fe、Si、P 元素和金属块体模板尚不存在。
元素文件保存的是带环境说明的展示半径，材料文件保存的是参考结构，不是导电率、燃烧热或生态效应数据库。
CsPbBr₃ 与 CsPbCl₃ 当前为程序构造的理想教学单胞，不能把这些坐标直接视为实验稳定相，更不能据此算太阳能电池效率。
旧的几何匹配度继续影响游戏收集节奏，不能偷偷变成物质纯度、净化率或“科研测得的性能”。
若首版采用铜铝比较，必须把新元素、块体身份、数据条件、商店供料与存档兼容作为显式工作包；不能只在星球里临时写两个数。

## 3. 数据应分成四本账

|记录|例子|允许的推导|不能混入的内容|
|---|---|---|---|
|结构样品|玩家摆放的 H₂O、晶胞快照、连接与版本|身份匹配、几何指标、研究资格|一份样品自动等于一吨产品|
|物性证据|某相、某温度、某纯度下的导热率|在明示范围内的材料比较|金币加成、剧本中的伤害值|
|工艺与产品|水箱、滤芯、导线、供电组件|物料流、组件性能、维护需求|仅因“含碳”就成为活性炭|
|世界规则|鱼群耐受曲线、居民项目优先级、事件冷却|校准过的游戏响应|伪称精确预测古生态或历史|

尤其要区分“游戏内完成测试”和真实测量：博士的实验动画不会凭空为未知化合物创造现实物性。
实验结果必须来自引用数据、明确适用的计算模型，或清楚标注的游戏假设；最后一种不能升级成“实验实测数据”。
这一边界仍允许很多创造玩法：自创几何可决定纪念雕塑、孔道造型和装配外观；标准组件提供已知功能；候选材料逐项进入有范围的研究。

## 4. 属性字典：先小而可用，再按产品增加

|属性|建议单位|必须附带的条件|产生的游戏选择|
|---|---|---|---|
|密度|kg/m³|相、温度、压力；多孔件另记体密度|运输质量与体积、轻量结构|
|电导率 / 电阻率|S/m / Ω·m|温度、相、组分、方向、样品状态|线缆损耗、绝缘与器件用途|
|热导率|W/(m·K)|温度、方向、致密度与相|散热器、保温壳、换热管|
|比热容|J/(kg·K)|温度、压力或路径、相|热缓冲、水冷与夜间保温|
|转变温度|K|熔化、分解等事件类型及压力|设备适用温区；不能都叫“耐热值”|
|低位 / 高位热值|MJ/kg|LHV/HHV、燃料状态与含水率|供热、发电、运输能源|
|弹性与强度|Pa|模量或屈服/拉伸等类型、方向、工艺|桥、外壳、工具；强度与韧性分开|
|孔隙率|无量纲比例|开孔/闭孔、测量尺度与方法|流体通行、轻量化；不直接等于吸附性能|
|吸附容量|mg/g|目标污染物、温度、浓度、水质、方法|滤芯容量与更换周期|
|膜通量 / 截留率|L/(m²·h) / 比例|膜型号、压差、目标物、进水条件|产水速度、能耗、浓水量|
|溶解度|明确的一种质量或摩尔基准|溶剂、温度、压力、pH 等|释放、结晶、盐度与回收|
|耐蚀或降解行为|指定条件的损失率或寿命|环境、载荷、封装、测法|海边维护、湿热寿命、回收|
|光学与光电属性|eV、谱函数或器件效率|晶相、温度、光谱、器件层和测法|光伏、窗、照明；带隙不等于组件效率|
|生态耐受|场景内响应曲线|生物群、介质、浓度、暴露时长|氧气、盐、营养盐的局部后果|

首版只启用产品实际需要的 4–6 项，其他字段为空并显示“尚无证据”，不要一次填满 30 个随机参数。
来源至少保存 URL、资料名、表或章节、获取日期、原单位、换算、样品条件、证据类别、适用范围和使用条款状态。
一个标量允许没有可靠误差估计，但必须写“原来源未提供”，不能随意加 ±5% 冒充测量不确定度。
真实数值用于档案和有边界的比较；可玩响应曲线与价格存在独立平衡文件，调价格不能改变铜的热导率。

## 5. 已核对、可作为首批比较的少量数据

NIST 所列 295 K 金属表给出：铜密度 8.96 g/mL、热导率 400 W/(m·K)；铝分别为 2.70 g/mL 与 235 W/(m·K)。[S1]
据此可以做“同尺寸的铜件导热更强但更重”和“同质量允许铝件做得更大”的装置比较；整机效果还受外形和散热边界影响。
不要从此推出铜散热器在一切条件下胜过铝，也不要把这些室温表值直接用于熔岩或超低温场景。
该 NIST 页面引用了早期物性手册，首版可保存为手册参考值；工业牌号、纯度及加工状态不能自行补写。
DOE 给出按低位热值比较的氢气约 120 MJ/kg、汽油约 44 MJ/kg，同时指出氢的体积储能能力与储存方式是另一约束。[S2]
这些数值只适合说明“单位质量热值”与“整套系统适用性”不同，不应把氢气设置成无条件最高级燃料。

## 6. 配方是“设备做什么”，不能只是材料名单

一条配方应声明：输入物与数量、适用输入规格、所需设备、条件、耗能、时间、输出、副产物、工具与催化剂、维护、岗位和版本。
输入必须区分消耗品、可回收载体、可重复使用工具；催化剂未必每轮全耗，但也不能默认永不衰退。
产品保存输入批次与性能依据；原子后来移动、旧材料重命名、配方升级，都不能改写已经出厂的产品。
配方分为“装配”“物理处理”“已定义的化学转化”三类。装配一个泵不需要宣称发生了分子合成。
首版可以用标准批次单位，质量与能量内部量纲仍要统一；未建立真实衡算之前不显示虚假的 kg 或 kWh 精度。
后续引入质量账时，样品数量不参与工业质量守恒，标准供料才参与；气体管线也必须有明确来源与去向。

## 7. 产品链候选：尽量让一个材料服务多条路线

下表是玩法抽象配方，不是实际制造说明；产率、能耗、门槛和产物规格须另建数据，未确认者保持待研究。

|链|投入与能力|产品及用途|可见代价或后续问题|
|---|---|---|---|
|供水|已识别水样 + 合格批量供料 + 装罐设备|水箱；盆地、灌溉、居民用水|缺运输、供水管未接通、储量用尽|
|增氧|合格氧源或空气 + 电力 + 曝气组件|局部增氧服务；缺氧试验池|持续耗电；有机负荷仍高时效果消退|
|供热|合格燃料 + 氧化剂 + 热设备|炉窑热量；烘干、取暖、加工|燃料补给、废热、碳排放等对应账目|
|燃料发电|燃料供给 + 发电设备 + 冷却|供电服务；泵、作坊、照明|效率损失、维护、热量要排出|
|储氢|水 + 电能 + 电解设备与储存组件|氢能载体与氧气副产品|占空间、设备消耗、回转后能量减少|
|燃料电池|合格氢供给 + 氧源 + 电池组件|供电、可回收水、余热|取决于整套器件与燃料供给，非单分子能力|
|导电|适配金属供料 + 线材工艺 + 绝缘组件|线缆卷；电网、通信设备连接|损耗、运输重量、绝缘维护|
|导热|适配金属 + 成型工艺 + 标准散热结构|散热器；工业与数据中心|风冷/水冷条件不足仍会过热|
|保温|合格低导热组件 + 外壳|保温墙、储热罐外衣|体积占用；不能拿来替代散热器|
|颗粒过滤|过滤介质 + 壳体 + 泵|去除指定悬浮物的模块|堵塞、反冲洗；水变清不等于可饮用|
|吸附|经工艺制得并验证的吸附介质 + 滤芯|针对某类污染物的处理模块|容量有限；饱和介质要更换或再生|
|脱盐|膜组件 + 压力设备 + 电能|淡水与浓盐水两股输出|高盐废流需安排，不能消失|
|盐的再利用|合格 NaCl 供料 + 指定再生设备|某类离子交换装置的再生服务|产生含被移除物质的废盐水|
|营养供应|合格营养配方 + 控量投放工具|作物补给；先解锁缺素诊断|多余营养随径流进入水域|
|机械构件|合格金属或复合材 + 加工能力|农具、桥梁构件、车架|质量、耐久、可维修性取舍|
|透明壳与光学件|合格玻璃/聚合物供料 + 成型|温室、仪器窗、封装罩|清洁、老化、温控与透光取舍|
|光伏|合格吸收层 + 电极等器件层 + 封装|太阳能组件；离网泵、屋顶发电|日照变化、湿热寿命与回收|
|电池储能|认证电极体系 + 电解质等组件 + 外壳|储能柜；调节昼夜电力|容量、功率、寿命与回收分开|
|抽象装备|合格构件 + 制造能力 + 物流|防护装备、工程车或军需装备|挤占民用材料、维修和人员；不细化实际武器制造|
|创意建造|自创结构外形 + 标准支架|展馆、纪念碑、站台与发光雕塑|收益由新颖表达与委托决定，不伪造工业物性|

DOE 的电解和燃料电池资料支持水、电、氢与氧之间的能量转换链。[S3][S4]
EPA 的处理技术概览支持按污染物和工艺区分处理能力、耗尽的吸附介质及废流；不能给所有滤芯一个通用“净水率”。[S5]
同样，NaCl 是可服务于某些再生工艺的资源，不应把“有盐”直接改写为万能净水或消毒效果。[S5]
钙钛矿光伏必须是多层器件与封装产品；DOE 把湿度、氧、光、热等稳定性问题列为研究方向。[S6]
不是所有钙钛矿都含铅；含铅配方的释放风险也应由具体成分、封装状态和环境共同决定。

## 8. 环境决定用途：四个能被玩家看见的故事

**氧气的两面。** 早期厌氧微生物盆地与缺氧鱼池使用同一氧源。前者的敏感群落衰退、避入低氧层；后者在适宜范围内恢复活动。
这不是“古代生物都怕氧”：氧化事件远早于泥盆纪等后续章节。需要一个早期微生物序章，或把厌氧微环境明确放在局部底泥中。[S7]
分别记录大气氧分压与水中溶解氧；投放位置、交换、消耗和暴露时间不同，不能共用一个全星球氧气进度条。
用几种群体的耐受曲线表示局部生态响应，数值标为游戏校准；出现部分死亡或迁移，而不是一投放就触发全星球灭绝。

**丰收之后的鱼湾。** 合理营养供应先让农田繁茂；继续堆料且遇到降雨，径流使下游藻类增多，随后分解消耗氧，鱼群迁移或受损。[S8]
玩家可以减少投放、截留径流、恢复缓冲带或短期增氧；增氧只是应急，不能无限抵消上游持续负荷。
演出按作物、雨水沟、藻色、鱼群活动分阶段发生，让玩家能追溯自己的行为，并有时间补救。

**高热值也会被地方条件限制。** 冷区聚落拿到燃料后先提出取暖与烘干工程，工业区则想扩建炉窑；缺氧微生物世界没有这些消费方。
如果只有燃料没有设备，它是仓库里的待用资源；居民须通过已有知识与建设材料完成项目，而非自动跳时代。
余热可以供暖，提高一套系统的利用，但不能被算成额外凭空创造的能量。

**同一导体的多种命运。** 发展中聚落可能把有限铜分给水泵、通信、照明或装备，每个项目有可见工地和受益者。
电力更稳定会允许更晚开工，也提高用电与维护需求；进入 AI 场景后还需计算设备、数据与散热，不是导电率够高就诞生 AI。
历史事件由资源、制度、知识和局部压力共同触发，材料只改变可选路径，不能简单保证某次战争结局。

## 9. 未知材料：有趣地试，不靠万能插值

已知材料查指定条件的数据；同族且位于验证范围内的组分才调用相应属性模型；超出范围返回未知。
线性插值需有明确自变量、同相同条件数据、中间验证点和误差评估；导电率跨数量级或相变时尤其不能直接连线。
禁止用原子半径平均值决定导电率，用原子个数决定热值，用 CsPbBr₃ / CsPbCl₃ 两端猜所有钙钛矿的光伏效率。
即使模型能预测带隙，也不能据此预测整机效率；Materials Project 说明电子结构计算的方法选择与常见带隙偏差。[S9]
新作品第一次获得的是“候选卡”：它有哪些可靠身份或几何信息、哪些用途值得筛选、还缺哪一种证据。
教授设计同条件比较与工艺窗口，博士运行具体测试，院士扩展模型覆盖或发现新结构族；玩家仍调整结构并决定取舍。
不要让研究费等价于真实物性解锁，也不要让雇更贵的人自动把不良材料改成优秀材料。

对希望任何作品都能改变地球的玩家，可后续提供独立“假设实验”开关：玩家选择未知属性区间，世界按该假设运行。
例如比较“如果我的候选很导热但易降解”与“若它导热普通但耐久”的不同世界，研究重点变成哪个属性最值得验证。
这比给每个未知材料随机抽五维属性更有教育意义，而且能立即进入用途探索；假设结果不写回真实材料档案，也不充当精品订单证据。
若使用游戏模型从可见孔道几何计算流通倾向，应写明它是几何玩具模型；球体间空隙不能直接称为实际晶体吸附容量。

## 10. 平衡和交易边界

样品是实验资格与收藏，批量供料是消耗资源，装置是耐用品，电与热是每个时步的服务流；工具箱不要把它们混成一种金币产物。
功率决定单位时间能带动多少设施，能量决定运行多久；电池既有容量限制也有输出功率限制。
若进入真实能量模式，统一记能量流与转换损失；电解—储氢—燃料电池环路不能回收比输入更多的可用能量。
如果采用标准批次的简化模式，只承诺游戏账目守恒；“1 份燃料”不能跨配方偷偷变换质量。
冷却水可以循环但要记热与损耗；废滤芯、浓盐水、废料均有去向，不能净化后把污染物凭空抹去。
奖励给首次发现、完成有约束的合同与维持有效服务，避免每次投料、每次失败试验或每次造废水都掉研究点。
采用同起点世界副本时，只复制世界状态，不复制浮岛可出售库存和可领取奖励；每次运货用唯一事务编号记录。
用于 A/B 实验的免费配给只能在实验副本消耗，不能运回浮岛售卖；同一发现是否跨副本计奖须明确去重。
供应需求可按“满足性能区间、成本、维护、置信范围”排序，精品不等于某个数值越高越好。
多种路线都应能完成任务：廉价大设备、昂贵小设备、低耗能慢方案；调节预算与场地，避免唯一通用最优材料。

## 11. 首个切片的独立取舍建议

原计划的水箱—盆地适合验证技术管线，但还不能验证“同一材料不同后果”的主卖点，不能拿它作为全部地球玩法的验收。
建议把首个公开可玩版本限定为 **试验水湾 + 两个生态对照格 + 标准供给设备**，不同时做七个时代与完整工业树。
第一段复用水样与水箱，把资源真正运到星球；第二段复用已有 O₂，玩家选择为缺氧水格增氧或观察厌氧微生物格的变化。
前者用少量鱼群代理，后者用表面微生物簇和颜色覆盖，复用水域底座；人口仅按群体更新，不逐个微生物模拟。
必须允许暂停、重置试验副本和查看同起点对照，否则玩家只看到随机死鱼，很难理解材料的作用。
下一版本再引入铜铝两种有数据的标准材料和可更换部件的散热试验台，验证属性、工艺、成本及装配空间的比较。
此后用同一配方接口接入滤芯、燃料与太阳能；新时期首先增加需求和场景条件，充分复用已存在的产品与规则。
把微生物、鱼类与现代站点视作独立试验场景，不能为了制作方便宣称它们自然同处于一个历史时期。

## 12. 这条材料线必须通过的验收

同一水/氧样品无论来自哪个模板，配方资格相同；氯化氢或含氧晶体不能因为有 H/O 就被当成水/氧源。
未知属性是缺失状态，不能按零或最高值参与合同排序；有一个已知属性也不能把整张候选卡认证为已知。
旧产品冻结输入与证据版本；修改结构、更新模型、切换温度都不会静默改变已经出货的性能。
任何工艺取消、双击、存档重开都不增加物料；同一货运不能同时到达两个世界。
玩家可以在画面中指出上游投入、设备动作、局部后果和补救选择；不打开长说明也能理解一次供给中断。
同一批氧源在两种明确环境出现不同结果，并且因果记录说明是生物群和环境差异，而非随机骰子惩罚。
调节游戏节奏只修改时间与响应系数，不修改有来源的物性记录；引用数据与游戏假设在卡片中始终分开。
