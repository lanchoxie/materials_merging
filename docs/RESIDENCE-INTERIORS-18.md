# 居住内景与生活互动（0.21.0 interiors-18）

本预览把浮岛上的住宅从“只能绕开的一块模型”变成了可以进入的生活空间。工程师小窝、博士公寓、教授公寓和院士别墅都有独立的程序化室内布局，住宅类别决定材料、家具组合和生活主题；不改变既有人员、容量或库存账本。

## 第一人称操作

- 在住宅外对准建筑按 `E`，进入对应内景；进入前保存浮岛位置和朝向，离开后恢复到门外。
- 门是可见的铰链门。对准门按 `E` 开关，开门后才能通过门洞回到浮岛。
- 对准椅子或沙发按 `E` 坐下，对准床按 `E` 躺下，再按 `E` 或“跳跃”起身。坐下/躺下时移动输入会被清零，避免人物滑走。
- 博士公寓和教授公寓在达到更高等级后会有更多楼层；室内楼层台按 `E` 切换楼层，每层都有对应家具和装饰。工程师与院士住宅用扩建家具、收藏陈列和庭院内容体现等级。

## 数据与性能

`data/residence_interiors.json` 只保存住宅风格、尺寸、等级上限和升级文案；`residence_layout.gd` 根据既有 `building_level` 生成家具清单，`residence_surface.gd` 负责室内碰撞，`residence_geometry.gd` 负责共享的程序化家具。这样数值与表现分离，住宅等级和家具数量可以调整而不改第一人称控制器。

室内是进入时才创建的独立场景，离开后释放；浮岛的校园人物和地面模型在室内期间暂停绘制，避免建筑多、家具多时持续增加渲染负担。

## 验证

- 205 项住宅布局、等级、门碰撞、家具可达性和场景生成检查通过。
- 78 项住宅 OpenGL 界面检查通过：从四类住宅门外按 E 进入、模拟触屏坐卧、按键与触屏起身、开门走出、手机返回键、升级、所有公寓楼层循环和重复进出释放。
- 现有第一人称编辑器 UI 回归 35/35 通过。
- 本轮未进行 Android 真机验证。

内景采用独立房间场景，门外与房间之间切换，尚不是外立面与室内一比一的无缝空间。楼层台切换当前楼层，暂不含可攀登的实体楼梯。家具是随住宅等级生成的预设布置，尚未开放室内自由搬动；泡面角和收藏柜是装饰，不扣取库存，也不额外产出奖励。坐卧是观看与休息姿态，不跳过生产计时。门、姿态和楼层在离开后重置；住房等级沿用已有存档。
