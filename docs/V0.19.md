# 0.19 铜铝层芯：研发、装配与性质订单

入口：广场邮箱 → 材料试验星球 → 我的材料 → 铜铝分层研发。

## 试玩流程

1. 元素商店买铜Cu和铝Al，在结构工作台搭一个同时含两者的提案，装入反应炉。博士会执行装炉，完成的样品仍需收集。一个2Cu+1Al的提案适合先试窄槽订单。
2. 收集后留档1份样品。建造并连路科研院所、教授公寓和博士公寓，招募1位教授、2位博士，启动「分层构件·热阻网络方法」。240金币、240标准科研工秒；只有团队到岗时工作，日程、休息和工资照常运行。
3. 研发完成后，选择沿层片或横穿层片传热、相同尺寸或相同重量，保存模型方案。左侧展示实际原子提案与独立的宏观层片，热流动画表示方向，不表示实测流速。
4. 在方案的装配页采购标准铜、铝层料，每包100g，分别22/12金币。单件工费24金币、48标准工秒；必须有连通工艺车间及实际到岗的工程师。与其他本岛订单共用人手，标准订单优先。取消返还预留层料，工费不退。
5. 成品可以拖到主世界现代城市的冷却回路，也能交付性质合同。窄槽买家限制截面和重量；轻量买家更重视质量，铝占比高的等重方案有不同优势。可交付、精品、接近目标的方案依次排在前面。

合同只接收已制造的层芯，达目标65%才收货，97%及以上为精品并多给1枚升级晶石。两个合同共用240秒采购冷却，参数集中在 `data/laminates.json`。订单目前位于装配页，尚未接入浮岛访客气泡；原有广场访客仍使用原订单系统，下一轮统一入口。

## 科学范围

研究的是标准层料的热阻网络方法，不能从任意Cu/Al坐标判断合金晶相或宏观性质。提案原子数比作为投料摩尔比，按摩尔质量及参考密度换算体积分数。构件保持两种致密、无反应、理想接触的独立金属层。

- 参考温度295K。铜密度8960kg/m³、导热率400W/(m·K)；铝2700kg/m³、235W/(m·K)。沿用[NIST参考表](https://www.nist.gov/ncnr/neutron-instruments/sample-environment/sample-mounting/reference-tables)，不是本游戏对玩家材料做出的测量。
- 铜体积分数 `f = (nCu·MCu/ρCu)/(nCu·MCu/ρCu+nAl·MAl/ρAl)`。密度按体积加权。原子量采用[RSC铜](https://periodic-table.rsc.org/element/29/copper)63.546及[RSC铝](https://periodic-table.rsc.org/element/13/aluminium)26.982。
- 沿层片 `k = f·kCu+(1−f)·kAl`，横穿层片 `1/k = f/kCu+(1−f)/kAl`，构件 `G = kA/L`。依据[MIT热阻网络说明](https://web.mit.edu/16.unified/www/SPRING/propulsion/notes/node118.html)。两个方向的区间是几何模型结果，不是统计置信区间。
- 忽略界面热阻、互扩散、金属间化合物、相变、腐蚀和寿命。电阻率、强度、毒性和误差范围保持未知。模型只用于295K附近的教学比较；城市温升采用既有教学映射，不是跨温区材料预测。共价半径只服务原子展示，不冒充金属平衡键长。

原始结构档案仍保留未知物性。保存的分层模型是另一份带来源、模型版本、条件和提案身份的不可变构件方案。自由填写的假设方案仍只能用于实验副本，不会被研发计时自动认证。

## 库存与保存

标准工业层料以kg独立于原子展示库存计账；每种最多5kg，含在制预留。层芯成品最多64件，所有设计共用32份结构/96份方案的档案上限。采购、预留、已消耗、制成、已售、已安装逐项守恒；主世界安装记录必须与制造账本一致。

实验副本从其复制起点另有6次模型安装，替换占一次，不消耗真实供料或金币，也不能把试用品带回卖掉。重置回到该副本的起点；起点里已有的安装保持，不会返还主仓库成品。主世界安装的旧层芯替换后不回收，本版尚无层芯拆解。

外层存档20、星球10、材料档案2、装配账本1。迁移旧档，保留既有假设方案及历史，新供料和成品初始化为零。真实0.18星球夹具纳入回归。Windows玩家原存档及备份在测试前后SHA-256均未改变。
