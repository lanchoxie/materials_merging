# 0.16 工业港 · 电力、余热与后方生活

完整闭环：有来源的铜铝电阻率/密度 → 同截面/同质量导线对照 → 制作导线与有限燃料/设备 → 星球径向配电 → 住宅照明、诊所、通信与工厂 → 运送民用或军需物资 → 故障与维修。两次大战背景各有独立起点、建筑/交通差异与单次中断事件；不能用材料选择推断真实历史胜负。

电学参考独立于295 K导热数据：20°C历史退火铜与EC-H19铝，明示牌号、来源及单位；R=ρL/A、I=V/(R线+R负载)，有限母线预算限制电流。恒阻负载、固定线温与整机效率是教学假设，不作实际工程设计。汽油44 MJ/kg低位热值来自DOE比较资料，油料、化学能、电输出、余热和散失闭合；没有免费回收循环。

固定六位代表居民与一台运输载具，只读实际行路、作业、货物和避难状态。损毁不自动恢复，工程师需走到设备、预留维修件、完成工时；优先供给居民或工厂会改变产出和生活服务。材料使用同一制造和交付入口，旧导线拆换计入封存废料而不退回可出售库存。
