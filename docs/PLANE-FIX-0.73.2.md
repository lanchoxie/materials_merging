# 0.73.2 · 修复手机放下飞机卡死

放下飞机时，需要找到地面、水面或屋顶。原先把无穷大高度转换成整数，再逐层向下查找；这个转换在不同处理器上的结果不同，可能让 Android 主线程陷入极长的循环。

现在，无上限或很高的建筑查询只检查实际存在的构件，地形查询先判断实际柱顶。无穷大不再进入整数循环；洞穴、挖过和填高的地面也使用相同保护。普通近地查询保留有限范围内的搜索。

提供普通版和开发版 APK，均为版本 0.73.2、Android versionCode 39，支持 ARM64 和 ARMv7。保留原包名与签名，供已有安装覆盖更新；开发版使用独立包名。

验证包括飞机放置专项测试、飞机飞行模型、背包放下→登机→起飞→降落→存档完整流程，以及建筑、洞穴、挖填和越野车回归测试。完整流程测试已跟随当前 F 键登机/下机操作更新。

已知验证边界：未连接 Android 真机，本次没有完成真机安装和卡死现场复测。盾构机原有测试有四项失败，已在修复前版本复现相同失败，涉及斜向掘进时的悬空判断，本次未改动盾构机行为。
