# 0.16 工业港 · 电、热与后方生活

广场邮箱 → 材料试验星球 → 工业港。选择一战或二战背景的虚构后方小镇，开启时暂停；先制造并投放设备，再推进观察。同起点实验使用独立有限配给，不花主世界物品。

## 怎么玩

1. 沿用合作工坊的水样入门资格，制造紧凑动力机组，拖到动力站；燃料罐拖到运输仓库。入门资格不代表水分子能变成汽油，燃料与设备来自明确的标准供应商。
2. 打开「导线对照」，分别记录同截面、同重量的铜铝计算结果，制作对应导线。住宅和车间槽位允许10 mm²，诊所和通信站允许4 mm²。
3. 给负载接线，选择居民、生产或通信优先；可安装余热回收器供暖。有限源功率依次分配，先到的负载仍要承担线损，剩余功率不足会限制后续设备。
4. 工人走到车间才开始加工。民用修复物资和军需维修物资共用原料、工时、电力与运输；切换订单保留当前在制批次，下一批才改用途。
5. 观察线路中断或警报：维修先预留一件备件，工程师到场后累计18秒工时。二战背景警报中居民沿路去避难，警报结束后恢复岗位。可暂停检修，投入和进度保留。

一战场景有小型轨道运货车，二战场景有卡车。两者统一使用液体燃料教学规则，外观不是对应年代的真实动力结构复原。运输途中保留货物，到仓才计入交付，返程也耗油；燃料耗尽时不能凭空继续行驶。民用/军需目前用于资源分配与交付对照，没有战争胜负、武器伤害或自动历史生成。

## 科学参考与教学规则

铜取标准退火铜20°C参考电阻率1.7241×10⁻⁸ Ω·m、密度8890 kg/m³；铝取EC-H19栏20°C电阻率2.8264×10⁻⁸ Ω·m、密度2703 kg/m³。与旧导热章295 K参考分开保存，牌号和条件不混用。来源：[NBS Circular 31，印刷页14](https://nvlpubs.nist.gov/nistpubs/Legacy/circ/nbscircular31e2.pdf)、[NBS Handbook 109，表1、印刷页5](https://nvlpubs.nist.gov/nistpubs/Legacy/hb/nbshandbook109.pdf)。

独立对照采用40 m回路、24 V、400 W额定恒阻负载。相同2.5 mm²时，铜线0.275856 Ω、铝线0.452224 Ω；相同889 g时铝线约8.22 mm²、0.137 Ω，因此等重铝线能降低损耗，却放不进窄槽。计算采用R=ρL/A和I²R，未模拟线温变化、交流、接触电阻、绝缘或安全载流。工业港有限源预算通过限制电流表达供电不足，负载有效电压随之下降，不宣称始终稳压24 V。

参考汽油低位热值44 MJ/kg来自[美国能源部](https://www.energy.gov/cmei/fuels/hydrogen-storage)。同页氢120 MJ/kg仅保留为参考，没有推出氢设备、储罐或任意分子热值。资料未给出的误差、温压细节与未知性质保留未知。

完整机组每秒最多耗0.0001 kg燃料，化学能25%转电、60%为可回收前的机组余热、15%其他散失。回收器利用余热的75%，住宅热需求上限1700 W；这些效率和需求是游戏设备方案。车辆每秒最多0.00002 kg，20%转机械功，其余记散热。通信人员到岗且有电可提高运输速度，此调度加成也是游戏规则。

总化学能＝机组电＋机组热＋机组散失＋车辆机械功＋车辆散失；电＝负载＋线损＋闲置；机组热＝住宅得热＋未利用热。原料、备件、成品、在途货物和拆下导线各有独立账本。生活温暖与诊疗服务是0—100教学指标，不是温度或临床健康预测。

历史仅提供背景：[GCHQ一战通信资料](https://www.gchq.gov.uk/information/communications-security-in-1916-the-la-boisselle-find)、[IWM一战无线电藏品](https://www.iwm.org.uk/collections/item/object/30005584)、[IWM二战配给与食物课程](https://www.iwm.org.uk/sites/default/files/files/2021-01/Health%20and%20Wellbeing%20-%20Food%20and%20Nutrition-%20Teacher%20Notes.pdf)。事件时间、损坏比例、固定六居民和各建筑是虚构教学方案；没有复用来源图片、模型或大段文字。

## 表现、兼容与验证

六居民按真实路线走到岗位或避难，工程师现场挥动工具。窗灯读取设备实得功率，热管与光点读取回收热量，工厂转轮读取作业状态；货物、车辆位置、裂痕与维修均从当前模型读取。固定居民和单辆交通工具控制建模量，建筑、轨道、树木等静态合批。模型、电学参考、显示和面板分离，历史上限60条。
