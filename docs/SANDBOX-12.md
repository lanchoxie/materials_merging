# 0.21.0-sandbox-12 · 林地与归途

从林地采集、改造地面，到把作品带回浮岛。本次是开发预览，不计入正式功能发布次数。

## 这次可以玩到

- 橡树、白桦、松树，四次斧击获得5份木料和1颗同种树种。树桩保留，退出和读档不会重新刷成成熟树。
- 树苗在生态时间中生长；消耗背包中的水样或标准水箱可以加快生长。普通作物仍通过种植箱播种、浇水、收获。
- 地形铲挖低一列地面获得土方；装备土方填高，库存随之减少。每列相对原地面最多上下6格，公共道路、桥梁及建筑/树根下方保持保护。支持地表改造，当前无地下洞穴。
- 生物与居民有生命值、怒气和追赶范围。温顺动物逃跑，护群动物及人类反击；暂停冻结遭遇，生态倍速不加速战斗。生命值耗尽可回营地恢复。
- 镜头前显示手和所持工具，走动有轻微起伏，操作时有挥动动画。
- 微缩器可收纳连通的自建作品，最多64块、边长8格。原物从河湾移走，不退款、不复制；有作物的种植箱先收获。
- 浮岛“河湾作品”可把作品摆到已开拓地块角落的展台。展出期间不能同时在星球展开；先收回，再放回世界。
- 浮岛第一人称漫步，与原经营场景共用建筑及居民数据。支持移动、跳跃、打开反应釜工作台和走光桥。房屋室内暂不开放。

## 数据与结构

`river_nature` 管理稀疏地形/林木状态，`river_combat` 管理实时遭遇，`river_miniatures` 转移构件所有权。数值分别在 `data/river_nature.json`、`data/river_combat.json`；背包只是原库存的视图。

渲染、碰撞、瞄准和存档使用同一份地形。修改仅使相邻区块失效，网格继续分帧重建；场景保留49个附近区块。浮岛漫步复用现有模型，同时停止后台经营视口的渲染。

旧版存档缺少新字段时以空地形编辑、无作品、满玩家生命值迁移；来源账本同时核对世界构件与微缩盒内构件，避免装箱复制材料。

## 当前范围

已有约1公里探索区域，未实现无限体素世界。树木使用三种程序化模型，物种演化和更丰富的战斗动作仍可继续扩展。材料与环境的互动遵循已有简化规则，本版增加的直接联系是水样浇树、采集原料加工与作品跨世界搬运。
