# 0.7 可玩版本

本版整合0.4至0.7的玩法，包含：

- 3D自由结构工作台、64原子上限、三轴拖动/微调、元素替换、任意两原子连接/键级、撤销、命名保存/复用、确认后应用到反应炉。
- 14种基础参考。已知分子根据拓扑匹配，未知、艺术或自定义周期作品保留探索身份，不能冒充稳定物质。
- 3D收购商走入、挥手、停留、离开；每次接待后默认20秒冷却，可送别；报价按可交付/精品/匹配/收益实时排序。
- 每第四位为创意收购商，3份展示样品换18金币，无精品与催化晶。
- 建筑免费搬迁、道路、围栏；完成3次交付解锁原子纪念雕塑。
- 科学家逐位加入，H–O、H–C、有限离子参考单元的谐振势数值优化。
- H₂高斯核回归：人工Morse数据61训练点、60独立验证点；只支持0.55–1.35Å。
- 两电子一维软库仑精确交换KS自洽模型：实际计算能量、密度和收敛历史。不是三维分子DFT，结果不会应用到三维炉内结构。
- 后台研究可取消，结果绑定样品指纹，旧结构结果禁止覆盖新结构；同样品/方法可缓存。计算免费，应用优化坐标单独确认编辑费。退出时中断任务可免费重启。
- 7版存档格式兼容此前1至3版存档；旧版新增元素库存初始化为0。玩家存档不随安装包分发。

数值算法、条件、单位及原始来源见 [SCIENCE-V0.7.md](SCIENCE-V0.7.md)。默认地图可拓展至128格。周期编辑是几何预览，未提供周期力场、真实材料带隙或导电率预测。
