# 0.21 河湾开发预览

2026-09-22。这是重做星球方向的首个可玩切片，尚未发布正式 0.21.0，不计入 QQ 的正式版本周期。正式 APK、发布标签和交付记录不变。

## 已实现

- 邮箱与工业成品工具箱新增河湾入口。旧跨时代试验台暂留，工坊与既有材料研究仍可使用。
- 连续阶梯地形、河道、高地和草甸；全景点选、局部近看与第一人称使用同一个世界，可旋转、缩放。
- 60 秒一昼夜、4 天一季；暂停、1/4/8 倍速。日照、植物配色随时间改变。离开河湾页面即暂停，浮岛生产继续。
- 水样和氧气样品直接从结构批次消耗，身份重读结构而非信任名称。工业成品复用原工坊库存。投放不收额外金币，失败不扣库存，材料足迹保留来源。
- 两种教学动物有独立身份、健康、饥饿、位置、任务和代数。成熟健康亲本繁殖，后代继承需氧阈值并有小幅变异。缺氧、断水、饥饿影响健康；启用自然补充时，恢复的开放栖地可以接纳新个体迁入，关闭补充可继续封闭灭绝试验。
- 谷物和芦苇消耗有限种子，生长受湿度、温度、营养约束。成熟后手动收获，所得种子与饲料进入星球粮仓。
- 结构构件包搭围栏；开关围栏改变自然觅食与饲料消耗。遮荫棚保水并减少光照。供氧器/颗粒过滤机先安装，再消耗有限补给。
- 年鉴记录换季、出生、死亡、收获、投放。事件最多32条，材料足迹最多256次；满额拒绝投放并保留库存。

## 试玩

邮箱进入“上帝星球 · 湿地实验（新）” → 选择河畔草甸 → 进入区域 → 播谷物 → 投放背包水样 → 4倍速观察 → 收获留种。去工坊做结构构件包，投到草甸后关围栏，观察饲料消耗。

独立端口的 Web 预览可能没有旧浏览器库存。返回浮岛，收集起始水反应炉产物即可；不会发放冒充旧存档的产品。

### 广阔探索区与自然补充（2026-09-22，当前修订）

- 当前构建标识为 `streamed-wilderness-3`。半径512米、直径1024米的有限平面地图；约1公里宽，尚非无限世界或球面。起始河湾之外有连续林地、河流、台阶高原与确定生成的栖地。边缘以海岸收尾，当前不能出海；高原边界使用缓坡。
- 16米见方的地形块围绕观察者加载，最多7×7=49块；每帧最多建1块。离开时卸载显示网格。树木查询缓存最多96块。地形与树木重建结果确定，不存整张地形网格，也不逐格建立节点。
- 按M或打开“背包 / 远行”进入远行页，可直接前往起始河湾、旅人林间营地、西岸林地和远方高原，也可步行抵达。E或面板按钮采集8米内成熟野生植被，获得1份星球饲料；这还不是视线选中单株植物的通用交互。
- 新栖地初始2只教学草食动物；每240模拟秒检查外来迁入，目标上限4只。起始四区仍保留既有繁殖与健康模型；开着的栖地在湿度、水量、温度、颗粒负担合适时补充，鱼还要求溶氧。关闭围栏拒绝外来迁入。
- 可采植被进度0到1的基础再生时间180模拟秒，成熟阈值90%，采后降到20%。动物觅食与旅人到来消耗植被。原有树林目前是地形景观，尚不能砍伐或种树。
- 营地最多2位旅人，食物充足时每150模拟秒接待1人，每人停留210秒；可看到进营、采集、休息、离营，以及名字、编号、当前任务。离开者不会作为原个体复活。当前并无居民家庭、人物性格、古代/现代聚落或完整人类社会。
- 栖地状态与显示分离；相同地点保留植被、个体编号、到访次数、再生/迁入计时。远郊只推进观察者82米内地点，远离后暂停；起始四区在星球页内始终推进。暂停和退出星球页停止模拟。可关闭自然补充，但原有动物继续活动、原有农作物仍按环境生长。
- 全图最多约196个合法栖地，额外配置上限300。存档仅保存已访问栖地状态；测试遍历全图后的这一字段约79KB，不含已有浮岛/材料存档。旧档缺少该字段会安全初始化，非法坐标/身份/容量/计时拒绝读取。
- 当前远郊环境是教学占位值；水/氧气和设施的效果仍只在起始四个试验区结算。远郊投放页明确引导返回起始区，不会暗中把库存投到旧区域。下一步需要局部环境、定点材料影响和通用对象交互。
- 地形数值在 `data/planet_exploration.json`，再生/迁入数值在 `data/river_population.json`。`river_chunk_stream.gd` 负责显示缓存，`river_population.gd` 负责持久生命与资源，`river_life_view.gd` 只显示，不产生物品。`planet_program.gd` 仍是操作入口。

## 架构与边界

- 数值与能力表：data/planet_v2.json。模型：planet_v2.gd。唯一库存事务：planet_program.gd。视图和面板分别为 planet_v2_view.gd / planet_v2_panel.gd。
- 模拟按固定秒推进，渲染不驱动交易/繁殖。静态地形树木合批，动物节点复用，水面/作物/设施仅状态改变时更新。普通文字更新不持续重建滚动列表。

- 投放成品不能同时在仓库里；拒绝伪造样品身份、免费建筑和非法环境值。玩家存档及备份本次测试未改动。
- 水位、湿度、需氧阈值等是游戏指标，不代表真实浓度；一份结构样品不是“一颗分子变成一湖水”。动植物为教学类型，时间压缩。
- 鱼类溶氧需求的定性依据：[USGS](https://www.usgs.gov/water-science-school/science/dissolved-oxygen-and-water)。遗传变异和选择原则：[NPS](https://www.nps.gov/flfo/learn/education/unit-three-background.htm)。本版阈值、出生速度等不是这些来源的实验数据，仅一个简化可遗传性状，尚无新物种分化。
- 未知结构保持未知。铜铝导热/电学组件仍在原试验台使用，不随意给它们添加未经验证的环境效果。
