# 0.11 星球试验台

这是地球章节的第一份可玩技术版本。已接通样品身份验证、装罐、工业成品、星球投放和实验副本；氧气生态、生物群落、真实材料物性与人类时代按主计划继续开发。

## 开始试玩

1. 打开广场的「邮箱 · 订单」，选择「进入材料试验星球」。
2. 领取一次性合作补给，获得2份标准供料。独立装罐台不占用现有工程师或科研人员。
3. 提交同一批次的2份已收集水样，解锁装罐。若缺水样，回浮岛收获水分子反应炉；水样不是工业供料。
4. 每次用1份供料和12金币，花25秒装出1箱水。后续供料每份18金币，含回收容器。完成后自动进入工具箱「工业成品」。
5. 按住水箱拖到深槽或浅台，松手提交；也可点选水箱后点击落点。移到空白处松手或按返回键取消，不消耗成品。
6. 水箱经8秒观察时间逐渐注入局部盆地。主世界总容量3箱，深槽水面集中、浅台更宽；这里使用游戏单位与预设地形规则。

取消制作会退回预留供料，已经支付的装罐服务费不退；按钮提前说明。金币、供料数量、时间和容量在 `data/planet_balance.json` 中集中配置。

## 三个世界位

保留1个主世界与2个实验位。主世界消耗浮岛生产的真实成品；实验副本使用独立的3箱虚拟配给，不能运回工具箱、出售或换奖励。

可从干燥盆地创建同起点实验，也可以复制当前世界状态。副本从暂停开始，先安排落点再开始观察。两个实验拥有相同起点和时刻时，可共同推进10秒并暂停比较。起点或时刻不同会提示，不能当作严格对照。重置只影响实验，主世界无法靠重置恢复资源。

离开星球后观察时间暂停，浮岛经营与装罐继续。只绘制当前世界，隐藏的浮岛停止3D绘制与动画。世界状态、装罐剩余时间、产品来源与交易序号一起保存；关闭重开不会重新领取补给或重复产出。

## 科学边界

水样资格依据保存下来的结构连接和元素身份重新匹配，不依据它最初来自哪个模板；HCl、NaCl、H₂和O₂不因包含某些元素而通过水样验证。旧样品后来怎样编辑，都不改变已提交的资格快照。

身份匹配不代表测得纯度、稳定性或水质；标准批量供料由合作方提供。局部水面变化不表示一箱水冷却整颗行星。本版本没有让研究动画生成未知材料的真实物性，没有新增免费能源或实验套利路径。

## 结构与存档

- `planet_program.gd` 协调样品、金币、装罐和投放的原子化交易。
- `planet_worlds.gd` 保存、复制和推进世界，无权访问浮岛钱包。
- `planet_view.gd` 用程序化模型显示状态，不扣库存、不发奖励。
- `planet_panel.gd` 处理星球交互和预览；邮箱与工业成品页提供统一入口。

存档版本11兼容1—10。旧档保留浮岛状态，新增尚未领取合作的星球；本版不保证旧程序能读取新存档。沿用现有临时文件替换和备份机制。

## 验证记录

369项有针对性的状态回归通过：154项基础状态、55项浮岛循环、19项小镇集成、98项结构一致性、43项星球状态。新增26项原生界面检查通过，覆盖邮箱入口、装罐、触屏/鼠标拖放、无效落点、点击放置、返回取消、世界切换和工业库存入口；13项浮岛打磨检查与原有邮箱/访客/工具箱流程也通过。

已查看实际渲染截图并修复副本之间的水面残留，改善盆地标记与填水表现。本机 Windows / RTX 3060 Ti / 1440×900 / 180帧采样：中位16.677ms、p95 16.753ms、最高203次绘制调用、455节点。这仅代表该场景与本机，不是Android或Web实测。

Android真机与最终浏览器交互尚未验收。包内资源、签名与导出资源加载结果另记在 RELEASES.md，不能用桌面触屏事件替代手机验证。
