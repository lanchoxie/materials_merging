# 0.12.1 · 给供氧器选一颗芯

2026-09-19。材料不再只出现在图鉴：对照铜、铝构件的导热与重量，采购供料包制造导热芯，再装进星球供氧器。高流量带来设备热负载，合适的构件能减少保护停机。浮岛、工业产品与生态观察形成了一次真实可玩的材料选择。

## 试玩路线

1. 广场邮箱 → 材料试验星球 → 底部「导热芯」。进入对照台会暂停当前世界。
2. 在「同尺寸」「同重量」间切换，观察测试棒粗细和热流光点，点击「记录对照」。这是参考物性下的计算方案，不需要把铜或铝伪装成玩家新发现的晶体。
3. 选择铜芯或铝芯，购买对应构件供料包，再支付16金币加工。每件24秒，与水箱、供氧产品共用已有工坊队列。
4. 先在生态舱安装供氧器，再把构件拖进去。厌氧池是窄槽支架，截面最多1 cm²；鱼湾是轻量支架，材料最多54 g。条件不符不会扣物品。
5. 放入氧气动力补给，调到2倍流量并继续观察。查看热负载、停机次数和氧变化；换下的旧构件会保留序号与来源，退回同一个世界的库存。
6. 实验A/B各有独立组件配给，可从相同起点比较。复制世界上的组件也只能留在实验库存，不会进入浮岛出售。

同尺寸问题中，铜芯更强但更重；同重量问题中，铝可以做得更粗。鱼湾的重量限制排除紧凑铜芯，厌氧池的窄槽排除等重铝芯，所以没有一件构件适合所有支架。低流量也可以降低热负载，但补氧速度较慢。

## 参考物性、模型与游戏规则

运行数据 `data/material_lab.json` 只录入四个物性事实：295 K下铜、铝的密度与导热率。出处为[NIST NCNR金属参考表](https://www.nist.gov/ncnr/neutron-instruments/sample-environment/sample-mounting/reference-tables)。原表密度g/ml换成kg/m³；这里采用自有字段和说明，没有复制整页表格、图片或书籍。原页面引用White 1979、CRC 1975，不代表NIST认可本游戏。

|材料|导热率 W/(m·K)|密度 kg/m³|记录温度|
|---|---:|---:|---:|
|铜|400|8960|295 K|
|铝|235|2700|295 K|

构件比较采用一维稳态导热 `G=kA/L`、`Q=GΔT`、`m=ρAL`。热流关系可对照[NASA TFAWS 2012课件第25页](https://tfaws.nasa.gov/TFAWS12/Proceedings/Form%20Factors%20Grey%20Bodies%20and%20Radks%20Course.pdf)。两端296/294 K、侧面绝热、295 K附近常数导热率均是明确的模型假设。光点表现稳态热流，不表现瞬态升温速度；未录入比热，因此也没有计算温度前沿。

整机路径另外串联0.5 K/W接触热阻、1.5 K/W外部热阻。这两个值是夹具假设，不是材料常数或测量结果。设备负载采用独立的0—100游戏指标：每秒按流量平方增加负载，基础冷却1.5，加上整机路径热导×18的调节量；到45保护停机，降至20恢复。它不是摄氏度、真实寿命或泵效率预测。停机期间不消耗氧气或电能，不凭空产能。

其他电导率、毒性、比热及参考值不确定度保持未知。不能从这四个物性推导任意新材料，也不能把玩家的键长评分当作宏观纯度。材料台只开放这四个明确设计；其余物性与合成表仍在设计草案中等待准入。

## 工程与存档

- `material_lab.gd`：有出处的SI计算、方案证据、尺寸/重量适配；不操作库存。
- `planet_thermal.gd`：独立的设备负载与冷却游戏模型。
- `planet_program.gd`：唯一的采购、加工、换件事务入口；引用报告与结构样品资格分开。
- `planet_ecology.gd` / `planet_worlds.gd`：设备快照、群体反馈、回看、副本资源；不扣浮岛金币。
- `material_lab_view.gd` / `material_lab_panel.gd`：程序化夹具与界面，不驱动物理或经济模型。

外层存档13、星球格式3。原0.11和0.12的真实存档夹具验证迁移：保留样品资格、供料、成品、在制进度、氧气/动力账本、历史记录与A/B共同起点，只补中性的热负载与空组件槽。旧基线在迁移前验证，迁移后才重算标识。

经济价格、工时在 `planet_balance.json`；教学热负载和支架限制在 `material_lab.json`。参考物性/几何模型为有版本的历史证据，不能直接覆盖旧版本后声称旧报告仍成立；将来换公式、物性条件或支架硬限制，需要新增模型版本或迁移已有安装件。已付费任务继续采用下单时的时长及工费。
