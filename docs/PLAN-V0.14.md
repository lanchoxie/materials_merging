# 0.14 · 居民会建造

承接0.13，而非完成整个地球目标。新增英国晚中世纪灵感聚落，以6个有固定职责偏好的代表居民表达家庭/工坊群体；不是逐人口历史复原。住宅参考Weald & Downland的Bayleaf木构厅屋，聚落水磨参考English Heritage对Wharram Percy的考古说明。模型和贴图均自制。

## 要交付的闭环

浮岛样品身份/参考设计资格 → 标准供应商组件 → 原有付费工坊 → 有序号的成品 → 聚落仓库 → 居民取用、走路、农作、磨粮、施工和工艺生产 → 供水/食品/工具/通行的下一轮需求。

新增生活饮水桶、结构构件包和农工工具箱。既有标准水箱只能供农作，不冒充饮用水；水样资格不证明饮用安全或工具强度，标准产品规格来自合作方。未知玩家材料继续保留未知，后续逐用途加入验收。

居民每次只能执行一个任务，先满足饮食，再选择可行工作。取料与工作地点分开，走路不算施工；消耗和产出有账本。建设项目只扣一次料，暂停保留进度；高级水磨/集市需要玩家批准。供水/工坊/河道三种偏好改变排序，项目有承诺期，不每秒改主意。四类新增建筑外壳：厅屋/粮仓、蓄水设施、磨坊、集市；道路、农田、脚手架复用基本几何。

浮岛新增工艺车间与人员岗位：工程师可选择施工巡检或车间；博士可选择自动、装炉收集、研发。已经参加课题的人员不能重复派往其他岗位。工坊保留合作方托管模式供新手使用，也可选本岛到岗工程师；未到岗不推进，薪酬与日常需求沿用现有系统。

## 验收

- 饮水与农作用水、粮食与加工食品、结构件、工具耐用量、工艺品分开；消耗、产出、外部投入与携带预留均可追溯。
- 不给资源时存在瓶颈，合理供料能使居民完成道路、蓄水设施、水磨或集市；材料通过行为改变世界，不能只改一个文字数字。
- 原生画面可观察搬运物、步行路线、农田、建造阶段、磨轮、集市与取食；数量固定，不随时间无限生成节点。
- 项目批准/暂停、政策、河道引水、同起点副本、历史与旧存档迁移可用；实验不返还浮岛资源。
- 同一工程师不会同时计算施工和工业贡献；博士岗位影响自动收集和课题选人；旧人员默认自动安排。
- 检查模型账本、真正到岗、重复交付、存档恢复、两种策略、UI、实际APK/Web包以及性能后逐版交付。

本轮仍无完整气候、疾病流行、社会阶层、战术战争与任意物性的万能预测。河道通行、工时、角色需求和产品份额是公开游戏规则。完整后续要求仍按EARTH-MASTERPLAN推进。
