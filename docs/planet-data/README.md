# 地球 E1 数据草案

这些文件属于设计草案，不被游戏导入；当前可运行版本为0.12.1，水箱/供氧配方和生态教学规则使用独立的 `data/planet_balance.json` 与 `data/planet_ecology.json`。这里的材料物性与扩展配方仍需逐项通过准入。

|文件|用途|
|---|---|
|property_seed.json|9 条带条件和出处的参考物性；误差未知保持 null；铜电导率由电阻率倒数派生|
|recipe_blueprints.json|13 条配方蓝图、34 个物品 ID；设备、消耗品、废物和电热服务分开|
|balance_draft.json|节奏、区域规模、副本上限、奖励规则与性能目标的初始提案|
|validate_design.py|检查单位换算、来源引用、配方引用、示例能量环路和副本防复制约定|

在项目根目录执行 `python docs/planet-data/validate_design.py`。通过检查只说明草案内部这些约束一致；不表示已经测量材料、校准生态模型或实现对应功能。

配方中的数量、工时和电量单位是游戏配置，不能解释为真实化工配比或效率。没有普适的“净水率”“毒性值”或“物性由原子个数计算”公式。每条蓝图的 `release_gate` 列出接入运行版之前仍缺的能力。

后续把完成准入的条目迁移到运行时数据目录，并为实际交易、存档和模拟行为增加针对性检查。真实物性、游戏参数和玩法假设继续独立管理。

完整范围见 [地球主计划](../EARTH-MASTERPLAN.md)，出处见 [资料目录](../research/EARTH-SOURCES.md)。

0.12.1准入记录：铜/铝在295 K的密度与导热率四个数值事实已独立复核并以自有结构录入 `data/material_lab.json`。附条件、出处、未知字段、模型和夹具假设；不批量导入此目录九条参考物性，不导入尚待验证的扩展配方。热导芯为有界教学应用，不是未知材料预测系统。
