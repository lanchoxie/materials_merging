# 0.17 现代城市 · 白昼之后

广场邮箱 → 材料试验星球 → 现代城市 → 开启并暂停。先安装光伏，决定有限电力如何分给居民、冷却、算力和回收；再用有损储能应对夜晚，用有限再生件建设公园。既有章节和同起点副本继续保留。

## 这一版的闭环

浮岛制造的标准组件进入城市，光伏把给定入射光的一部分变为电。白天负载用不完的电才进入电池，充放各90%，往返81%；新电池为空，功率上限与容量各自独立。计算机组在操作员走到算力中心后才工作，电能计入热池；散热不足会停机，降至恢复线后继续，不丢在制工时。

夜间照明调度和冷却排程各需100标准计算工时，分别降低对应需求25%、持续180秒。结果是有限时间的教学优化，不增加电源、不叠加倍数，也不是现实AI节能承诺。更换下一项任务保留当前任务；两位操作员分工计入真实岗位。

回收设备每批预留2份废构件，24标准工时后得到1.4份再生件和0.6份残渣。废料用尽会停产，残渣不消失；回收工人用4份再生件、30现场工时建出口袋公园，居民此后才会沿路去休息。建园会暂时占用原来的回收人员，暂停保留投入，继续不重复收费。物料份额是游戏构件当量，不冒称千克。

## 光、电与热的边界

一个游戏周期240秒，其中150秒有日照，75—105秒经过云影；峰值900 W/m²。P=辐照度×安装面积×假想组件效率×保留性能；未建组件不记录该面积入射光。没有温度修正、逆变器、遮挡几何或完整天气预报。电网使用理想汇流，0.16铜铝导线的线路损耗模型仍保留在工业港，没有声称现代网络已逐线求解。

储能容量150 kJ，最大充电1000 W、放电900 W。自动模式只在不足时放电、剩余时充电，不同一秒自充自放；保留模式只充不放，关闭模式两者都不做。电池化学、老化与安全未建模，不能用此游戏容量评价真实电池。

算力默认950 W、居民320 W、风冷80 W、回收180 W，配电顺序由玩家选择。计算电力全部进入热池；热池采用1000 J/K的假想整体热容、8 W/K被动热导。安装散热芯后，295 K铜铝夹具的整机热导乘以独立教学缩放85，再乘实际风冷功率比例；这不是把参考金属性质外推成现实服务器预测。相对热池28 K停止、12 K恢复；界面优先显示积热kJ，避免冒称CPU温度。风扇耗电单独计入负载，没有凭空制冷；计算热被明确转移到环境。

账本分别检查：入射光＝转电＋未转电；光伏电＋电池放出＝负载＋充入＋弃电；充入＝放出＋剩余储能＋损耗；计算热＝剩余积热＋散出热；外来/拆换废料＝库存＋预留消耗；消耗＝再生件＋残渣＋在制投料。再生件进一步区分库存与建园耗用。
