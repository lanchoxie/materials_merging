# 0.18 我的材料：留样、假设与用途试验

入口：浮岛广场邮箱 → 材料试验星球 → 右侧「我的材料」。先领取合作补给，然后选择已收集的反应炉样品。留档消耗1份，重复的同一结构不重复扣除；最多32个结构、96个方案。

## 可以怎么玩

1. 留下一份自己搭出的分子或晶体，查看独立结构指纹和真实原子布局。未匹配参考的作品同样能进入档案。位置与连接保留，展示只缩放居中，不自动优化或确认稳定性。
2. 选择散热芯或导线，选择同尺寸或同重量，主动勾选并填写用途所需的密度和导热率/电阻率。输入是玩家提出的假设，不是博士测出的性质。没有填写的性质始终未知，不默认填零。
3. 保存不可变方案，进入现代城市或工业港。开启章节，复制实验，把左下角的假设构件拖到落点。也可点选构件后点落点。主世界拒绝假设投放。
4. 从同一个起点创建两个实验，给两边不同构件，再同步推进。现代城可比较积热、冷却与停机；工业港可比较负载功率和线损。材料与几何一起决定结果，等重导线可能太粗，无法安装在诊所窄槽。
5. 每个实验的现代/工业章节各允许6次假设安装，替换也占一次。不会扣真实工业成品，也不能带回主岛出售。重置恢复该副本创建时的状态和剩余次数；从已经用过的实验复制，会保留其既有安装与次数，不凭空补满。标准器件与假设插件分别记账；再装标准器件会解除相应假设插件。

## 科学范围

档案记录可匹配的结构身份，但宏观物性仍未知。当前没有从任意原子组合推出电导率、毒性、带隙或寿命的模型，也没有把数值输入伪装成实验测量。原始档案不会因为玩家填写假设而变成认证材料。

每个方案只保留本用途所需的假设。导热条件为295 K、长0.1 m；同尺寸面积0.0001 m²，或同重量0.054 kg。计算 G=kA/L、m=ρAL，并串联0.5与1.5 K/W的假想接触/外部热阻。现代城市沿用既有教学冷却映射和能量账本，不能用来预测真实设备温度。

导线条件为293.15 K、往返总长40 m；同尺寸截面2.5 mm²，或同重量889 g。按 R=ρL/A 计算，接入既有24 V恒阻负载与有限供电预算，线损进入能量账本。忽略温升、接触、交流、绝缘和载流能力，不提供真实接线设计。

铜/铝参考仍独立保留在材料/导线对照台，沿用0.12.1与0.16核验的NIST/NBS来源，不把参考数值自动赋给玩家样品。来源入口见 material_lab.json、electrical_lab.json 与 research/EARTH-SOURCES.md。数值范围、容量、安装限制集中于 data/player_materials.json；这些范围是游戏边界，不是材料可合成性证明。

## 版本与数据

外层存档19、星球及世界9。真实0.11至0.17夹具升级时不生成免费样品、方案或库存。新存档以完整浮点精度保存，避免小电阻率等SI值在JSON转换时损失精度。结构名不参与身份，原子顺序、坐标、连接、模式和晶胞条件参与；目前不做旋转/原子重排的化学同构去重，也不声称指纹就是化学物种标识。

修正实验起点标识：字典键统一按字符串排序，保留旧标识校验和迁移；世界账本对亚微单位浮点残差采用既有精度，方案指纹仍保留微小SI输入。旧档与新档往返、同起点对照、只读历史、拒绝重复投放和篡改证据均检查。

档案、条件计算、事务入口、模拟与展示分离。模型只读取安装方案，渲染不扣资源。已有样品、保存方案、已安装构件和历史快照相互独立，不因后续编辑变更。

## 下一步

此版提供假设驱动的可玩实验入口，尚不能把自创材料变成带真实物性认证的商业产品。后续建立有适用范围的材料家族估计、参考校准与博士/教授科研任务；把研究结果与条件、误差、工艺配方和下游订单接起来，再开放符合资格的主世界用途。不能用等待计时替代真实预测依据。

完整地球目标仍在进行。Android真机手感、存档/后台、持续温升与跨系统试玩需要继续验收。
