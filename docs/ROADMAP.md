# 原子工坊：持续迭代计划

2026-09-22 当前方向：旧材料试验星球及其时代场景已退役，后续只扩展可第一人称探索的河湾世界。浮岛工坊、材料研究与订单独立保留；各时代将基于同一地形/生命/材料交互系统重新设计。下文已交付版本是历史记录，不代表继续维护旧世界。见[退役记录](PLANET-RETIREMENT.md)。

目标是点击 + 收集 + 沙盒：玩家亲手摆放原子，在自己规划的科学小岛上生产、交易、开拓，再逐步认识材料计算。每个版本先完成可玩闭环、验证与存档兼容，生成带版本号的 APK 并保留旧包用于比较。按用户最新要求，QQ 从 0.14.0 起每累计 10 个正式功能版本发送一次最新 APK；用户单独要求的修复包及时发送。交付规则与记录见 [DELIVERY-POLICY.md](DELIVERY-POLICY.md)。

## 保留的核心约定

- 炉子必须放进真实地块；三种建材来自生产收获，用来开拓。
- 每台炉拥有独立结构。原子编辑费随炉子等级变化，同等级每次费用固定。
- 收购商提出需求；接近需求的样品可折价交易，精品额外给升级材料。
- 工程师加速建造，科学家逐个体系解锁研究。
- 盲盒有金币、材料和伙伴，展示概率及保底；试玩阶段只用游戏金币。
- 装饰、住房、小人物、任务与稀有物件支撑 DIY，不让科研成为唯一玩法。
- 几何、经验势、机器学习势、DFT分层；未计算的真实物性保持未知。

## 0.3：元素仓库与替换（已交付）

先做有可靠参考数据、满足明确条件的元素替换，再扩展任意沙盒。

1. 元素商店、库存、购买价格、购买确认与替换消耗预览。
2. 为原子记录元素、价态、配位数与所属结构版本；替换前展示是否有适用参考。
3. 支持的一组分子/晶体变体，更新原子颜色、尺寸、参考几何和收益；不能换元素后仍沿用旧分子的科学结论。
4. 无数据的组合标成“探索样品”，只给受限的探索收益，不伪造稳定性或真实物性。
5. 应用一次修改按该炉等级收固定编辑费，元素成本单列；预览和取消免费，保留撤销。
6. 补充新体系前逐条核对来源、适用条件、单位及许可，添加相应卡片。

## 0.7：机器学习势与DFT教学任务（已实现教学版）

实际训练H₂人工Morse数据的核回归模型，并独立验证；计算两电子一维软库仑精确交换Kohn–Sham模型，显示真实计算的曲线、密度、方法、范围和失败状态。此一维模型不是三维分子DFT。后台任务绑定样品指纹，优化结果单独确认费用后应用，旧结果不可覆盖已改变的样品。目前没有支付或外部计算服务。

后续优先推进手机真机体验、周期结构与表面/缺陷数据，再考虑外部三维DFT与可信物性订单。

## 数据库原则

当前用本地JSON足够，不需要先搭服务器。数据量变大、有复杂检索、账户同步或真实计算任务时，再迁移到SQLite或服务端数据库。

元素记录保存原子序数、半径类型与条件、展示信息及来源；结构记录保存化学计量、坐标、连接、周期性、占位和参考条件；经济规则单独记录。科学参考改变需要重新核对，调游戏金币只修改经济规则。重复显示晶胞或复制同一个结构不应自动刷高科学复杂度。

## 每版验收

核心玩法能完成一轮；新数据有出处或明确标记教学构造；存档迁移与经济交易有检查；桌面鼠标及触屏仿真通过；APK签名、包内资源、版本号验证通过。没有安卓设备时明确标注未真机测试，不把桌面检查写成手机验证。
