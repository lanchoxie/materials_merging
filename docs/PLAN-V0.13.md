# 0.13 · 河流记得你投下的东西

范围：三个连通水域，两个古生态灵感起点，物质守恒的营养—藻类—有机碎屑—再矿化链，有限过滤、收割、植被缓冲、供氧与水箱冲洗。复用已有样品资格、供料/工坊/成品、设备组件、副本/存档框架。

## 这版要玩到的两段故事

1. 上游短期变绿、下游晚些时候缺氧。玩家对照“持续增氧”与“限制上游输入+湿地吸收+把生物量收走”。鱼可向外缘迁移，底栖群体不能迅速离开；恢复有延迟，死亡不撤销。
2. 滤过的水更清，仍可在下游重新长藻。机械滤网截留藻/碎屑颗粒，不截留溶解营养；滤盒会饱和或耗尽动力，旧滤盒中的物质转入本世界封存废物。透明不等于饮用安全。

## 边界

所有营养池采用同一种游戏营养当量，不声称是实际氮/磷比、kg或mg/L。藻/植物池只追踪对应营养份额，生长/死亡/分解相互转移；这是明确简化的生态教学模型。输入、出口、封存废物均记账，氧为独立教学指标。自然复氧、植物与藻的生长条件固定，未复原全球气候。

只有预留的土地径流营养和购入实验供料能增加总营养；冲洗只改变流速和出口，不消灭污染。季节/光照/分层暂不参与，营养、颗粒、鱼及底栖响应分别显示。工程设备为浮岛带来的试验装置，不暗示泥盆纪有工业。

晚泥盆纪灵感：鱼群、较开放的林地；晚石炭纪灵感：高大的石松/木贼式植被与湿地。有不同缓冲空间与初始存量的明确游戏场景，不能把两种不同起点称为严格同条件对照。不加入年代精确预测或全物种食物网。

## 验收

- 三水域顺流转移，至少一拍延迟，不因遍历顺序瞬间贯穿；全局营养账本在操作、克隆和保存后闭合。
- 藻增长消耗营养，死亡转碎屑，分解再释放；有延迟耗氧与恢复，鱼迁移和损失各有记录。
- 机械滤盒有容量、动力、截留物、旧盒封存；不去除溶解营养，不承诺饮用性。收割有限，植物不能无限吸收且其残体可归还营养。
- 水箱/供氧器/导热芯可进入连通水域，设备与供料分开。新配方的资格只证明教程/身份，供应商提供规格，不能把原子结构当滤材实测。
- 三世界保持各自时代、库存配给、初始条件、历史与设备来源；旧版世界增加未启动的新水域，不改已有进度。
- 程序化场景有河道、藻斑、碎屑、植被、鱼、过滤与收割动作；观察记录、曲线、因果提示和历史预览可用。
- 检查解析守恒、延迟、处理目标、有限资源、两条干预故事、存档迁移、触屏投放、实际导出包与性能，再交付0.13。
