# 0.12 氧气的两面

从“装水”进入第一个生态实验：同一种供氧设备，让敏感厌氧菌毯退缩，也让缺氧鱼湾里的鱼群有机会回游。这是两个隔离的教学生态舱，不是同一时代的地球复原。氧、覆盖和群体数量采用游戏指标；本版不声称预测真实物种或完整古生态。

## 从浮岛生产

1. 在空地建造「氧气双星 O₂」反应炉，收集同一批次的2份样品。也可用沙盒搭出有匹配参考的O₂结构；样品原先来自哪个模板不影响身份验证。
2. 从广场邮箱进入星球，领取合作。底部选择「供氧器」，在「生产工坊」提交O₂样品解锁工艺。水中的氧不能代替O₂；水样和氧气样品资格独立。
3. 买1份供氧器组件包（42金币），支付20金币、等待35秒，得到1台便携供氧器。拖到一个生态舱安装，每舱最多一台。
4. 选择「补给盒」，买1份氧气动力供料包（24金币），支付10金币、等待25秒，得到1盒运行补给；拖到已经安装供氧器的生态舱。
5. 一盒包含有限氧气和已充能动力模块。正常流量可运行60秒，0.5倍可运行120秒，2倍可运行30秒。气泡、储量柱和状态卡表示是否正在供给。关闭设备暂停消耗，耗尽后停机，随后才可补入下一盒。

合作方供应标准原料、组件和已充能模块；玩家的结构样品用于进入工艺，不凭几何打分生成真实纯度。供氧设备不免费发电，装好一台也不意味着无限供氧。取消制作退还正确类别的预留供料，已经支付的工费不退。

## 两个生态舱

|操作|厌氧微生物池|缺氧鱼湾|
|---|---|---|
|开始观察|低氧适合本情景的敏感菌毯|鱼群沿开放通道离开低氧鱼湾|
|持续供氧|粉色敏感菌毯缩小，绿色耐受群体扩张|氧指标逐渐上升；条件改善后外湾已有鱼群回游|
|改变连通|小池隔离后保护幸存敏感群落；接通会暴露于主池环境|关闭通道阻止迁移，持续缺氧可能造成滞留鱼群损失|
|停止供氧|氧降低后，主池幸存者可恢复；若主池已经消失，需要在适宜条件下接通仍有幸存者的小池才能重新定殖|随着持续耗氧，鱼湾可能再次变得不适宜；供氧并未消除缺氧原因|

鱼群账本区分湾内、外湾和累计损失，不靠迁移生出新鱼。敏感群落在主池与避难池都消失后，也不会自动重生。近景鱼和菌毯是群体的代表模型；动画不会决定死亡数量。

生物响应方向参考 [Smithsonian 早期生命](https://naturalhistory.si.edu/education/teaching-resources/life-science/early-life-earth-animal-origins) 与 [NOAA 低氧水域](https://oceanservice.noaa.gov/facts/deadzone.html)。温度、盐度和食物在本实验中保持适宜，外湾是预设的适生边界；氧不是mg/L，没有模拟全球大气。阈值、速率和时间压缩属于独立游戏规则。

## 对照与回看

保留主世界和两个实验副本。实验各有2台虚拟供氧器、4盒虚拟补给，水箱仍有独立的3箱配给；这些物品不能搬回浮岛。可以从初始生态或当前状态创建实验，也可把已有实验换成初始生态。主世界不能这样重置。

建议两个实验都从初始生态开始：A给厌氧池供氧，B给鱼湾供氧；安装后加入补给，同步推进6次、每次10秒。比较同一时刻的菌毯、鱼群、氧指标和消耗。不同起点或时刻无法冒充同条件实验。重置只影响所选实验，运行中的主世界设备和浮岛库存不变。

每5秒保存一次生态观察快照，最多保留120份（约10分钟）。「回看过程」暂停当前世界，用滑块查看过去的群落、设备、气泡和曲线；回看时不能投放、扣库存或改生态状态。「回到当前」返回暂停的当前世界，继续由玩家决定何时运行。观察记录说明暴露、迁移、损失、耗尽和恢复等原因。

## 结构与数值

- `planet_ecology.gd`：固定时间步的群落、耗氧、迁移、有限补给、观察记录和校验。
- `planet_ecology_view.gd`：复用程序化几何显示菌毯、鱼、通道、避难池与供氧器。
- `planet_ecology_panel.gd` 与 `planet_ecology_chart.gd`：局部控制、曲线和回看。
- `planet_program.gd`：按配方处理供料、工时、样品资格、成品和原子化投放；显示层不能扣钱。
- `data/planet_balance.json`：供料价格、工费与工时；`data/planet_ecology.json`：生态参数、补给与来源边界。

数值调整后，已经付费的制作任务保留原报价和剩余工时。新任务使用新数值。变动物种、配方身份或模型含义仍须升版本并编写对应迁移，不能把参数变化冒充新实验数据。
