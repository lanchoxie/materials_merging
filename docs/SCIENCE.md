# 材料岛 Demo：科学数据与近似边界

本版把材料结构用球、键和晶胞展示。玩家看到的「参考几何匹配度」比较当前坐标与已选教学模板的几何关系，随后换算成游戏产量。它不是势能，不证明结构稳定，也不预测带隙、导电率、反应速率、毒性或材料性能。

## 模板数据

坐标和距离使用Å，角度使用度。1 Å = 10⁻¹⁰ m。模板的位置是根据下表构造的教学坐标；小数位截断会产生极小的几何舍入误差。

| 模板 | 数据库ID | 当前参考 |
| --- | --- | --- |
| 氢分子 | `hydrogen` | H–H约0.741Å |
| 水分子 | `water` | O–H约0.958Å，H–O–H约104.5° |
| 甲烷 | `methane` | C–H约1.087Å，四面体角109.47° |
| 理想立方CsPbBr₃ | `perovskite` | 教学晶格6.30Å，Pb–Br为3.15Å；不是实验晶格或室温基态 |

H₂、H₂O、CH₄的参考键长采用[NIST CCCBDB实验键长表](https://cccbdb.nist.gov/bondlengthmodel2x.asp?basis=21&method=2)中的实验列。不要把同页的计算列或拟合值当成实验参考。水的[单分子实验数据页](https://cccbdb.nist.gov/exp2x.asp?casno=7732185)列出约104.4776°，演示取104.5°。甲烷使用理想四面体的几何角，约109.4712°，演示取109.47°。

一个元素对没有放之四海皆准的平衡键长。同样是C–H，化学环境、键级、电荷、电子态及数据定义都可能影响其数值。本版把参考绑定在具体模板，而没有把「元素A+元素B」等同于所有分子中的真实平衡距离。

## 半径

| 元素 | 展示半径/Å | 类型与条件 |
| --- | --- | --- |
| H | 0.31 | 共价半径 |
| C | 0.76 | 共价半径 |
| O | 0.66 | 共价半径 |
| Cs | 1.88 | Cs⁺有效离子半径，配位数12 |
| Pb | 1.19 | Pb²⁺有效离子半径，配位数6 |
| Br | 1.96 | Br⁻有效离子半径，配位数6 |

共价半径来源：Cordero等，*Covalent radii revisited*，Dalton Transactions (2008)，[DOI:10.1039/B801115J](https://doi.org/10.1039/B801115J)。本次资料访问中出版商页面返回访问限制，数据库保留原始文献引用；正式扩充数据库时应再次逐项核对原表及其不确定度。

离子半径来源：Shannon，*Revised effective ionic radii and systematic studies of interatomic distances in halides and chalcogenides*，Acta Crystallographica A32 (1976)，751–767，[IUCr文献页](https://journals.iucr.org/paper?S0567739476001551)。有效离子半径取决于价态和配位环境，不能当作孤立中性原子的固定尺寸；半径相加本身也是近似。

共价半径和离子半径是两种不同定义。本版在元素记录中保存`radius_type`，展示时也应保留说明。球体缩放、颜色、碰撞阈值是界面与游戏规则，不是电子密度等值面，也不意味着原子具有刚性的表面。

## 钙钛矿教学单胞

数据库构造一个6.30Å的理想立方单胞：8个角点放Cs，体心放Pb，6个面心放Br。屏幕上共有15个原子球，但晶胞周期共享后，计量为：

- Cs：8个角点×1/8 = 1。
- Pb：1个体心×1 = 1。
- Br：6个面心×1/2 = 3。

因此化学式是CsPbBr₃，而不是Cs₈PbBr₆。体心Pb周围的6个Br构成八面体；相邻周期单胞通过共享角点连接这些八面体。

Pb²⁺与Br⁻在本表中的半径和为1.19+1.96=3.15Å，再乘2得到教学晶格常数6.30Å。这只是构造示意的规则，不是CsPbBr₃某温度、压力下的实验晶格常数，也不能从该值推出稳定相或带隙。图鉴明确标为理想立方教学模型，不代表室温基态。

当前使用的是带周期共享计量说明的有限晶胞视图。编辑可以打破它的理想对称性；代码没有完成周期边界邻居重建、周期力计算、晶胞应变、相变或分数占位分析，因此不能把任意编辑后画面当作已经求解的周期性真实材料。

## 几何分数怎么算

记模板目标键长为`r₀`、当前键长为`r`。每条模板键的分数为 `exp(−[((r−r₀)/r₀)/0.22]²)`，权重为1。模板键角使用 `exp(−[(当前角度−参考角度)/18°]²)`，权重为0.45。共点向量无法定义角度时，此角度得分为0。

有`cell`的模板额外比较所有原子对与参考单胞的相对距离，每对权重0.08，相对距离宽度0.15。目的是让移动角点Cs也会影响匹配度；这些比较项不代表新增化学键。

再对异常接近的原子施加碰撞惩罚：当原子对距离小于其展示半径和的0.45倍，就乘上距离与阈值的比值。远处未成键的原子不会因为没有接近某个半径和而被判错。分数最终限制为0到1。0.22、18°、0.45、0.08与0.15都是调节游戏手感的参数，不是实验拟合的势函数参数。

这一设计具有平移和旋转不变性，适合演示键长、键角和明显碰撞。它没有电子结构、真实力、长程静电、温度、熵、色散、化学反应或不同化学计量之间的可比能量。高分只表示更接近当前参考，而不是在所有可能结构中最稳定。

## 科学家当前能做什么

本版只解锁H–O水分子的「参考几何辅助」：把玩家坐标恢复为已知水模板。没有迭代求解、能量最小化、真实H–O势或机器学习模型，不应在界面写成「DFT优化完成」或「找到了全局最低能」。

未来可增加四个彼此明确区分的层次：

1. **几何启发**：保留现有即时反馈，学习半径、键长、键角、配位和晶胞计量。
2. **真实经验势**：为指定元素体系与适用条件选用可验证的势函数，显示能量和力的单位；跟踪参数版本、边界条件和局部收敛。
3. **机器学习势**：记录模型支持的元素、训练域、参考理论层级及外推警示，不把未知体系自动当作可预测。
4. **DFT研究任务**：通过独立计算服务调度，提供方法、基组/截断、赝势、k点、边界条件与收敛标准；结果附计算元数据并与结构版本绑定。

后续买家若真正要求带隙、模量等属性，必须绑定已计算或可靠查得的属性及条件；在数据缺失时显示未知。当前订单只使用几何匹配度，避免把代理分数伪装成这些属性。

## 数据维护约定

新增模板应记录化学式、原子顺序、单位、坐标、参考键长/角、出处、数据定义、适用条件和是否为程序构造。晶体还应记录晶胞、周期性与占位计量；缺陷结构需说明缺陷类型、浓度和电荷态。来源与游戏奖励应分别记录，修改奖励不能改变科学引用。

模型测试已覆盖四个模板的参考分数、碰撞惩罚和刚性平移不改变分数。它们验证实现与设定一致，不验证该代理模型可替代真实材料计算。
