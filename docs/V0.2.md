# 0.2.0 · 开拓小岛

## 土地

初始9格的索引保持不变，地图为坐标地块集合。相邻边界随着开拓追加，只可购买与已开拓土地四向相邻的地块。当前开放上限128格，保存边界最多1024格。这是本版容量限制，不是承诺无限地图。

每种建材的单格费用：`2 + max(0, max(|x|, |z|) - 1)`。不另收金币。开拓失败不会消耗材料。拖动地图、按钮缩放、右键/按钮旋转；“土地”面板按边界与已开拓土地筛选并定位。

近处最多36块完整建筑，远处简化；道路、草坪和土层使用批量绘制。当前人物继续在核心区域巡检，尚未实现全岛寻路与岗位分配。

## 收益

`金币/秒 = 0.8 × C × (0.15 + 0.85q) × [1 + 0.45(L−1)]`

`C = min(4, [1 + 0.55√(N−1) + 0.30(E−1) + 0.12√K] × 章节系数)`

- `N`为模板计量原子数，`E`为元素种类，`K`为模板键长与键角约束数量。
- `N−1`和`E−1`下限为0；晶体按占位权重计算N，CsPbBr₃的15个展示球合计5个原子。
- 分子章节系数1.0，晶体1.25。这些是游戏数值，不是物理定律。
- `q`是0至1的参考几何匹配度，`L`为炉等级。建设中的炉子没有收入。
- Lv.1满匹配：H₂约1.34、H₂O约1.83、CH₄约2.22、CsPbBr₃约3.12金币/秒。
- 复杂度依据受控模板计算，坐标编辑不会改变拓扑复杂度，只影响几何反馈。未来增删原子时需要重新定义有效连接与计量规则，不能直接把原子数量当奖励。

产物周期、建材掉落、盲盒、工程师建造速度、升级费、固定等级编辑费延续0.1。收益平衡变化只影响更新后的生产，不改已积累的金币和库存。

## 收购商

四位买家继续轮换，每单3份，目标98%，同类样品相差不超过5个百分点为精品。精品价格为 `round(该订单结构复杂度 × 50)`，另给1枚催化晶。普通交易保持按几何差距、同类0.75/异类0.40折价，最低15金币。

独立面板列出每台炉的实时库存、精品/同类近似/异类替代评级与报价。库存不足或建造中不能交付；预览与成交共用同一个报价函数。当前需求仍是几何与类型，不是真实带隙等物性。

## 数据与存档

- `data/elements.json`：元素半径、类型条件、颜色、来源；目前6种元素。
- `data/materials.json`：四种结构、坐标、几何参考、晶胞占位、科普卡。
- `data/economy.json`：复杂度系数、产出系数与订单数值。
- 存档版本升至2，自动迁移0.1的版本1；Windows保存在项目saves，Android在应用私有目录。
- 包名、签名保持一致，Android versionCode由1升至2，可覆盖升级保留应用数据；不需卸载旧版。

尚未实现元素购买/替换/增删原子、全岛寻路、真实势函数与DFT。它们在[后续计划](ROADMAP.md)中分版本推进。
