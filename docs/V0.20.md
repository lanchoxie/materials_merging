# 0.20 广场契约

材料研发终于回到浮岛生活：完成铜铝分层方法后，性质收购商会在正常来访轮次进入广场。窄槽仪器商开汽车，轻量载具商骑自行车；入场、停车、下车、等候、成交装货、离岛均由实际访客状态驱动。

## 怎么玩

1. 在广场邮箱查看铜铝研发路线。它根据真实元素库存、样品、方法研发、方案、在制任务和成品给出下一步，并能直接进入对应页面。已有进度无需重做，也没有重复发放的任务奖励。
2. 制成层芯后等待性质收购商。所有客人共用3个广场位置；每次生成访客的基础间隔65秒，入场6秒、等候240秒、离岛5秒。符合条件时，每3个访客轮次中的一个用于性质采购，两类需求轮换；至多一个性质商人在场，不增加渲染人数上限。
3. 亮起的气泡直接交付当前最适合的合格成品。灰色气泡可点击，打开该客人的性质条件、候选排序和不足原因。手指可以直接滑动报价列表。
4. 性质订单按构件热导、最大截面和最大质量验收。有货且可交付者优先，其次用途适合度和精品。至少65%目标才接受，97%及以上为精品；保留原金币与催化晶规则。候选的比例不是万能材料评分。
5. 成交后车上出现铜色/银色层料货箱，客人载货离开。重复点击、客人未到场、已离场、超出规格、只有假设方案或没有成品时不会扣货/付款。主动送别和等候超时均空车离开。成交后的性质采购冷却240秒，之后仍需等待下一轮来访。

装配页现在只保留前往邮箱的入口，不能绕过来访频率直接售卖。常规样品买家仍能收购结构批次，未被性质订单替换。工业工具箱新增玩家模型成品和标准铜铝供料；只列真实库存，避免几十个空成品卡片挤满页面。

## 科学和数值边界

0.19的295K分层热学模型不变，来源与范围见[V0.19.md](V0.19.md)。本版没有添加新物性或把未知作品认证成合金。合同里的最低比例、精品比例、价格、奖励、来访频率属于游戏规则。

`data/island_balance.json`控制共享访客数量、时间与性质轮次；`data/laminates.json`控制两种用途需求、报价及车辆。已到场合同保存当时条款及指纹，修改新订单报价不会在当前访问期间悄悄更改承诺。模型候选与成交使用同一个库存和报价服务；`material_contracts.gd`负责适配共享订单，`material_journey.gd`只读取实际进度生成引导。
