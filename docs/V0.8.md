# 0.8.0 · 科研小镇

本版本将人员、道路、住房和研发组成一个可玩循环。保留已有的原子编辑、科学模型、生产订单和收集玩法，键长始终由玩家调整。

## 从哪里开始

底部「科研小镇」可查看居民、招募、建造、团队研发和心愿。点击地块后选择「小路 · 庭院 · 建筑升级」，可以布置当前地块。

1. 收获水分子反应炉的金币，建工程师小窝并连路。旧工程师会自动入住空床位。
2. 在空地建科研院所和博士公寓，确保小路连接迎客广场。
3. 花45金币招募博士生，再用60金币开展硫化氢基础配方课题。
4. 有院士别墅后可以招募院士，与2名博士生开展进阶课题。每位院士同时主持1个进阶课题；本版共有2项进阶课题。
5. 教授是可选导师，安排到同一个课题、到岗后，让最多4名博士生的研发效率提高50%。研究完成解锁配方，手动替换元素的探索方式仍保留。

## 角色与费用

所有金额均为游戏金币。游戏一天480秒，工资按在岛时长累计，每480秒结算；没有离线计薪。

|角色|招募费|日薪/津贴|职责|
|---|---:|---:|---|
|工程师|85|8|沿道路前往反应炉施工、巡检、从食堂给院士送餐|
|博士生|45|4|独立基础课题或参加进阶研发；偶尔散步、去公园休息|
|教授|520|24|可选导师，提升同课题博士生效率；公寓、食堂、院所之间生活|
|院士|1400|60|每人主持一个进阶课题；别墅与院所通勤，有工程师送餐|

缺钱时只支付可用余额，剩余计入欠薪；工作效率暂为75%，手动补发或下次结算付清后恢复。不会扣成负金币，也不会自动删除角色。已离岛人员的已产生薪酬仍需支付，后续不再计薪。招募费用不退。

博士生的认真程度、饥饿、心情、研究专长影响实际贡献。必须到达工作地点才推进建造或研究；休息、吃饭和通勤时没有科研贡献。进阶课题的院士未到岗时暂停。人员不可同时加入两个课题，院士离岛时课题保留进度等待补员。

住宅床位和院所工位限制招募；不同院所分别分配工位。食堂、公园的容量目前是建筑配置，尚未实现排队占座。本版非反应炉建筑直接落成，工程师施工进度用于反应炉；院士别墅、食堂等的独立建筑施工阶段留待后续。

新开拓土地的小路需花8金币铺设，相邻的已铺道路自动连通。每块普通地可放1栋主建筑及外围8件小物；护栏相邻槽位自动接起来，长椅、花盆、灯、成就杯可共存。成就杯完成3次交付后解锁。收纳退还物件原价。

迎客广场保留交通空间；收购商按自行车、汽车、小巴轮换，停车下车、步行接待、回车离开。交易/送客冷却继承订单规则。车辆动作是表现层，订单可交易状态由访问计时决定。

## 居民心愿的初始节奏

入住后前120秒不触发。每60秒全岛检查一次，45%概率产生1条；每日最多3条、待办最多5条，同一人至少隔480秒。请求960秒后自然收起，暂缓/婉拒无惩罚。

- 房间改造：45金币，心情+16，增加舒适度，不增加床位。
- 搬家：25金币，心情+20；必须有另一栋匹配住房的空床。
- 家人小聚：35金币，心情+18；记录一次探亲事件，不增加永久居民。本版尚无家属独立模型。

性格会调整事件抽取权重：社交倾向高的人更容易请求小聚，认真的人更容易提出房间改造。心愿在专用面板集中处理。

## 数值与模块

- `data/campus_people.json`：招募费、日薪、研究配方和团队需求、教授加成、昼夜时长、行走速度、送餐耗时、心愿概率/冷却/成本。
- `data/campus_buildings.json`：建筑价格、容量、层级、升级费、小物和小路价格、电脑/手机显示预算。
- `data/economy.json`：金币产率、收购商订单和访问冷却。
- `campus_sim.gd`：人物日程、住房/工位分配、行走、课题、心愿，无UI或钱包依赖。
- `campus_payroll.gd`：计薪与结算，无场景或钱包依赖。
- `campus_layout.gd`：道路拓扑、容量与空间数据。
- `campus_view.gd`：场景显示、车辆和人物动作；不改人物收益和任务进度。
- `campus_panel.gd`：展示与操作入口，通过 `lab_state.gd` 统一验证交易、扣款和保存。

## 性能、兼容与边界

人物逻辑每秒更新；生产每0.2秒推进；世界视图每0.5秒同步。道路使用MultiMesh批处理，静态建筑只在布局或可见区域改变时重建。电脑同时渲染最多24位居民，精细地块预算36；Android为12位/16块，关闭MSAA和实时阴影，帧率上限30。未显示的人仍按同一逻辑生活，不影响经济结果。

本机Windows（RTX3060Ti、1440×900）在128地块、96居民、32反应炉场景采样240帧：中位帧耗时16.7毫秒、95分位16.8毫秒（本次采样约60帧/秒），采样期间静态场景重建0次。详细报告见 `artifacts/campus-performance.json`。这不是Android真机或浏览器帧率承诺。

存档格式8，兼容旧版本；原地块索引和建筑保留，迎客广场增设在边缘。工资和途中行走可存档，旧存档不会追缴离线工资。网页版使用浏览器本地存储，与Windows/Android进度独立。

此版新增课题使用现有参考数据，没有声称发现真实新材料。科学计算仍沿用0.7的限定教学模型。旧产物编辑前仍需先收获/交付；独立库存批次、多套候选人员面试、家属实景、更多建筑美术与安卓真机调优列入0.8.1。
