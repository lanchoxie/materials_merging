## 继续推进顺序

1. 完成跨章节「观察手册」：从真实世界事件解锁科普与用途卡，记录干预、条件和代价；同起点两个副本的差异用图与场景定位展示，不另造一个文明总分。
2. 优化长历史保存/恢复和频繁面板刷新。保持原完整账本验证，不能靠减少验证或清空旧历史获得表面性能提升。
3. 增加第二类有范围的材料/工业链，优先从真实来源明确的能量转换或指定污染物处理入手。先定义 SI 账本、设备效率、废物出口与可视代价，再扩展配方；不直接把任意晶体认作滤芯或太阳能板。
4. 对生态盐度、繁殖等尚未实现项目建立可控规模的区域模型与独立来源，避免增加大量独有3D模型。
5. 全流程试玩、跨章规则审计、30分钟运行与实机验证，逐项对照原需求再判断整个目标完成。

当前结论：继续开发。0.20是材料研发与浮岛交易之间的重要接通版本，不能替代完整地球目标验收。QQ以较新的DELIVERY-POLICY.md为准，旧目标文本中的取消约定已被用户后续要求覆盖。
