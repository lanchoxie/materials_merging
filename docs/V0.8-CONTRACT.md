# 0.8 模块边界

人物逻辑、工资、布局、3D显示和UI分别位于 campus_sim、campus_payroll、campus_layout、campus_view、campus_panel。lab_state 是唯一的钱包/存档/交易入口。人物模块返回操作报价；只有 ready 为 true 时状态层才扣款。表现层不贡献科研或施工进度。

CampusSim 接收 buildings、reactors、road_links、reachable_plots、plaza_plot、coins、templates 上下文。人物沿路段移动，到岗才工作。保存 current_plot、next_plot、movement_progress 等，渲染层平滑插值。工资模块只返回应扣金额，钱包由状态层处理。研究项目通过 requires/optional 声明必要和可选成员，同一人最多参加一个项目。

CampusLayout 管理 cardinal 邻接路网，缓存随 revision 失效。地块索引稳定；每块保留一个主建筑字段和独立 props 列表。老 house/garden 仍对应工程师住房/公园。非反应炉建筑当前即时建成。

CampusView 以模型状态绘制场景，每0.5秒同步，帧内仅播放动作和插值。旧绕圈人物关闭。WorldView 管理地块底座、旧反应炉和镜头可见预算；CampusView 管理新建筑、道路和人员。两者属于同一表现层，共享坐标体系，禁止反向驱动模拟。

CampusPanel 通过 state.campus_* 门面操作并发送 changed(message)，主界面负责刷新、提示、保存。人员和研究报价每秒刷新。配置文件和可调参数见 V0.8.md，避免在界面中计算经济规则。
