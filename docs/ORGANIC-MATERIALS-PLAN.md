# 有机物：从反应釜走进生态

2026-09-24 · 有机物分阶段计划。organic-14 已实现首个切片：尿素参考结构、共享样品、车间配料罐、有限配水分装、局部种植补肥与过量伤苗。organic-15 补齐从元素、博士装炉到反应釜产物收获的实际链路，见 [反应釜合成](ORGANIC-15.md)。配水与种植见 [有机物入门](ORGANIC-14.md)。organic-16 新增乙醇、甘油的反应釜合成、单物质配水、分装倒回与分物质守恒，见 [三种有机物](ORGANIC-16.md)。真实毒理、饱和溶解度、糖/醇加工与动物暴露仍为后续内容。

## 玩家会玩到什么

先把“制造—使用—观察—改进”做成可见的小故事。浮岛产出仍进入现有背包，工艺车间负责加工，星球设施接收具体批次；不给星球另造一套用金币购买的材料。

|拟议小章节|玩家行为|画面反馈|研究的用途|
|---|---|---|---|
|一杯糖水|比较少量、多量、未溶解部分；选择放进配料罐或留下作物种子|罐底晶粒逐步减少，超过容量保留固体；面板可看条件与剩余质量|测定溶解度和溶解速度，不能把二者当成同一个性质|
|谷物工坊|将谷物送到工艺车间，通过抽象的发酵与分离工序制作有机成品|工人在车间搬罐、管路流动；成品交给合适的器件|解锁工艺条件与产率，而不是替换一个原子就解锁万能工艺|
|小溪的变化|比较同一种物质在隔离池中的不同投放量与不同生物反应|动物改变饮水点，鱼群游向适宜水域；观察镜显示变化原因|区分直接毒性、缺氧、酸碱等不同原因，支持留样和空白对照|
|纤维与薄膜|用同一建筑蓝图换不同覆盖材料，观察吸水、耐候和寿命|雨天表面吸水或形成水滴，植物因遮光发生生长差异，工匠更换老化件|材料数据描述成品及条件，不能把单体性质直接当作聚合物成品性质|

这些是候选玩法，具体化学物质和数值必须经过数据核查才能启用。首批控制在约4种有机参考物质、2条加工路线、2种用途；不同时加入完整代谢、食品营养、疾病或真实化工仿真。

## 数据延用现有物性记录

扩展 `docs/planet-data/property_seed.json` 的“数值—单位—条件—来源—证据类型”格式，运行时接入现有 `player_materials` 登记与样品批次。设计数据与游戏实装分开；`runtime_import_enabled` 在校验与玩法验收前保持 false。

新增记录建议：

- **水溶解度**：指定溶剂、温度、必要时 pH、盐度及物质形态；单位保持一致，原文数值和换算过程同时留存。可混溶液体单独描述，不能填一个臆造的有限饱和值。
- **溶解速度**：另存游戏反应速率或有依据的动力学模型；它受表面积、搅拌等条件影响，不由溶解度直接决定。
- **毒理效应**：每条记录带物种/生命阶段、暴露途径、持续时间、终点、浓度或剂量及单位、数据出处。不能用一个“毒性80”同时代表鱼、植物和人。
- **环境行为**：降解、挥发、吸附等只在有依据且已实现对应过程时启用。缺失信息保留 null；“未知”不等于0或安全。
- **可燃性/热值、营养、气味等**：分别建模；可燃不代表可食，能提供能量不代表适合所有生物。物质和器件输出要通过配方/能量效率连接。

IUPAC 将溶解度定义为指定溶质在指定溶剂中饱和溶液的组成；这支持把条件与物质身份一起存储。[IUPAC Gold Book：Solubility](https://old.goldbook.iupac.org/html/S/S05740.html)

PubChem 的 PUG View 可取得性质注释及来源，但不同物质拥有的栏目并不相同。导入时保留原始来源、条件和证据类别，不把计算值、第三方摘录与实测值合并成一个看似精确的常数。[PubChem PUG View](https://pubchem.ncbi.nlm.nih.gov/pug_view/)

生态风险需要同时考虑暴露及其影响，也需要公开数据和模型的不确定性。游戏将这一原则简化为“投放去向 → 暴露 → 生物响应”；以下具体玩法模型是本项目设计，不是真实环境风险评估工具。[EPA：About Risk Assessment](https://www.epa.gov/risk/about-risk-assessment)

## 投放不是全星球加减分

每个有交互的水池/土壤小区记录体积、各物质剩余质量、温度以及少量环境变量。只更新玩家附近和已激活设施，远处保留摘要。首版只做静态小池，不开全地图流体与任意化学反应。

投放一份样品时从原批次扣除，进入“未溶解—溶解—沉积或已消耗”的去向账本；已知条件下才按溶解度限制溶解质量。反应、移出和流失都留有限记录，不能凭空清空或增殖物质。先把水样的游戏份数正式换算为声明过的游戏体积，再谈浓度；不把 ranch-13 的1份水当成1升真实水。

生物因饮水、摄食或接触获得累计暴露。行为先反馈：避开、停食、离开栖地、繁殖变慢；严重时才影响健康。表现要说明原因，不让任何红色液体都通用地“扣血”。设置观察镜显示可见迹象与已知/待研究原因，未知影响保留问号。

## 玩家新材料仍然有用

新结构先拥有身份、来源、数量与有限的已知性质；玩家可留样、给科研团队测定、或在隔离池里做对照。研究成功得到的是有适用范围的性质记录和工艺资格。

只有在相同物质、相同条件体系且数值范围足够时才考虑插值；不按“含碳多少”“分子长得相似”直接推断可食性、毒性或任意新材料的可靠参数。教学估算明确显示“模型估计”与范围；超出范围返回未知。未知材料仍可用于外形展品和不依赖未知性质的合成步骤。

## 开发顺序与验收

1. 统一质量/体积与批次账本，新增条件化性质记录；先验证溶解与存档守恒。
2. 一种参考有机物、一个可见配料罐、两种投放量；颗粒、透明度和观察卡片一致。
3. 隔离水池的接触与生物行为，至少一个有明确来源的生态终点；缺数据时不启用推断。
4. 工艺车间的有机加工路线、材料覆盖件与村民维护，连接现有农牧仓库。

验收须覆盖：同批次重复投放、满容量拒绝、不同温度条件、未溶解残留、移出后余额、保存重进、未知物性、不同物种与暴露途径、关闭加速后反应持续时间，以及手机上的实际帧率。每一步单独做可玩的开发预览。
