# 0.15 白垩纪栖地与迁徙

将晚白垩世海尔溪启发的区域群落接入现有工业交付和星球副本：有限补水、遮荫与通道改变栖地，恐龙按饮水、食物和捕食压力寻找可达区域。复用工坊事务，不生成第二个钱包。

四个区域、两条原生通路与两条可修复连接；三角龙、埃德蒙顿龙、霸王龙是固定数量的代表个体。追踪位置、行进进度、渴饿、健康、死亡原因、迁徙和捕食。死亡不会因重新进入界面或补水自动复活；不做繁殖、进化、遗传和真实种群预测。

两种新成品：栖地连接桥、遮荫保水棚。前者允许所有动物通过，后者降低蒸发并降低光照下的植被增长；水箱补给有限水量。雨旱循环由固定模拟时间驱动，水、植被与遗骸分别记来源和消耗。初始条件、周期、需求、阈值与效率全部放入独立 JSON，并标为教学规则。

画面显示水面缩小、蕨类减少、不同轮廓的恐龙实际走路、喝水/取食和栖地连接。静态几何合批，固定显示上限，隐藏场景停止动画；人物与生态逻辑不依赖帧率。侧栏以区域选择、行动原因和干预为主，详细账本按需展开。

验证：有限成品与失败不扣费；开桥改变可达性且不只允许食草动物；关桥不让在途动物瞬移；水和食物有限、捕食不凭空造食物、死亡不回滚；账本拒绝篡改；运行与 JSON 保存恢复一致；0.14 真实夹具迁移；同起点副本隔离；触屏/鼠标交付、历史只读、布局截图与性能采样。发布 APK/Web/源码，按交付规则累计版本，不立即 QQ 重发。
