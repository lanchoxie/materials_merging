# 0.5 收购商访客与订单排序

## 这版的玩法变化

收购商现在是一个会到访的角色，而不是永久停在面板上的按钮。打开“来访收购商”时会显示访客入场标识和轻微摇摆动画；完成交付后，访客离开，下一位买家需要等待冷却结束才会重新接待。

访问冷却是游戏数值，当前为 20 秒，配置在 `data/economy.json` 的 `orders.visitor_cooldown_seconds`。它只限制交付动作，不改变反应炉生产和金币增长，后续可以按章节、建筑或活动调整。

## 订单排序

市场列表会为每台反应炉生成一个候选报价，并按以下因素综合排序：

1. 当前可以完成交付；
2. 是否达到精品条件；
3. 是否与买家要求属于同类结构；
4. 几何匹配度；
5. 预估金币收益。

每张报价下方会显示排序理由，例如“精品匹配 · 可获得催化晶”“可交付 · 近似报价”或“同类样品 · 还缺库存”。权重放在 `economy.json` 的 `orders.ranking_weights`，方便后续平衡。

排序是辅助决策，不会替玩家自动交付。未知组合仍然明确标记为探索组合，不会因为排序算法而被误判为稳定材料。

## 科学性与可玩性

目前订单只使用数据库中的结构参考和几何匹配度。收益、精品和排序分数都是游戏规则，不能解释为能量、带隙或导电率。后续扩充 baseline 时，每个可收购结构都应同时补齐元素组成、参考坐标、结构类别和可追溯来源；没有可靠参考的数据继续走探索样品路线。

## 验证

- 状态测试：包含市场排序、排序理由、冷却拦截和冷却恢复。
- 旧订单交付流程保持兼容。
- 冷却时间、动画时长和排序权重均可在 `data/economy.json` 调整。
