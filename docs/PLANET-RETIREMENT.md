# 0.21 开发预览：旧材料试验星球退役

2026-09-22。用户要求移除已经放弃的材料试验星球及其逻辑。本次为 `single-world-4` 同版预览修订，不新增正式发布或QQ计数。

## 当前只保留一个星球

邮箱与工具箱进入“上帝星球 · 河湾世界”。可第一人称探索、分块加载、种植、采集、动物繁殖/迁入和旅人营地继续使用 `planet_v2` 与 `river_*` 模块。没有旧盆地、厌氧池/鱼湾试验台、旧时代副本、旧工业港或现代城市入口。

旧玩法的25个模型、场景、面板与图表脚本已从 `scripts/` 移除。旧时代环境数据库不再加载；旧投放、世界切换、复制、重置、回放、同步推进、时代启用等指令不再接受，也没有后台模拟旧世界的对象。

旧代码与依赖旧玩法的测试以 `.txt` 原文移到 `docs/archive/legacy-planet/`，供历史追溯，既不作为游戏脚本执行，也不导入安装包。历史正式APK、Web包、标签不重写。

## 浮岛独立保留的能力

- `factory_panel.gd` / `factory_view.gd`：独立工坊、材料留档、铜铝分层模型、参考导热/电学计算；不加载旧星球渲染器。
- 工坊 → 有限成品库存 → 河湾投放。铜铝层芯仍可研究、制造和交付浮岛性质订单；尚未接入新星球的用途不显示虚假的投放入口。
- 工坊合作补给、原样品身份验证、在制任务、供料、工费和工程师到岗规则继续保留。`data/factory_recipes.json` 独立提供配方；旧库存所需的配方身份元数据仍可读取，但不重新启用旧玩法。
- 玩家假设档案保留为条件计算，不变成实测物性或免费成品。

## 旧存档

内部工坊/星球字段版本10升级到11，外层存档版本21继续兼容。新档不创建 `worlds`。旧档的 `worlds` 原样放入只读 `retired_planet` 字段，只通过精简数据读取器检查旧装备身份与账目；没有模拟类、显示入口或奖励。它不会退还已经消耗的材料，不从虚拟副本产生库存。

保留旧装备账目是为了让现存的层料守恒、已安装数量、现有成品和在制任务继续一致。读入和下次保存不改变玩家的供料、研发、设计、库存或订单进度；原文件测试时只读。今后若决定回收旧设备，需要另行设计明确的迁移交易。

## 验证

工坊界面25项：邮箱和背包无旧入口，独立工坊生产真实水箱，在当前河湾扣库存投放，返回工坊停止河湾观察，材料档案/热学/电学/层芯模型仍可操作，订单入口可达。导出包11项资源检查通过：旧场景、旧数据不在PCK，当前河湾、工坊、再生配置仍在；历史归档也未进入包。

浮岛状态154项、性质订单40项、性质访客界面27项、触屏滚动15项、河湾模型48项与界面26项通过。后续打包验收与校验值追加于本文件。桌面原生检查不等于Android真机或浏览器内性能验收。
