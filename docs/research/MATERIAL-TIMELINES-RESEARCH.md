# 材料驱动的多时代沙盒：调研与范围建议

日期：2026-09-22。根据用户要求调研 Minecraft、程序生成沙盒、生态经营及人物模拟。本文是设计提案，不是已实现功能或正式发布记录。用户确认了多时代、组织与人物性格的方向；具体数量、算法和开发顺序仍是本轮建议。

## 1. 调研结论

用同一套材料、环境、生命、生产与人物行为规则承载多个时代。时代改变起始生态、已有知识、基础设施、组织形式和美术；同条件下的材料性质不随时代标签变化。

世界按需扩展，详细模拟范围有上限。玩法深度优先来自材料用途、当地能力和不同利益诉求的组合。先做同一河谷中的两个有区别的起点，再扩充年代与地理。

核心循环：浮岛创造材料 → 验证性质/加工成品 → 第一人称交付或安装 → 环境与当地生产能力变化 → 生物行动、居民组织项目 → 新需求与可带回的样本/作品。

这些资料能证明可用的设计手法，不能证明我们的数值、性能或教育效果已经成立。

## 3. 时代、时间线和流逝时间

三个概念分开：

- **时代起点**：初始物种/环境、当地工艺和组织的内容包。可包含早期微生物、古生物河谷、古代聚落、近代工业、现代、未来等不同起点。
- **时间线**：从某个起点或已保存节点发展出的独立世界，有自己的干预记录、人口和建筑。玩家的不同选择形成不同历史。
- **模拟时钟**：日夜、季节、生长、个体生命周期与生产所用的时钟。当前60秒一天、4天一季是河湾游戏节奏，不代表每4分钟完成一个真实地质时代。

普通游玩观察一地发展；跨越很长年代时采用有说明的阶段推演或切换到独立时代起点。首次版本不尝试真实模拟从微生物到人类的数十亿年。未来科技属于推测/科幻内容，需要与真实参考材料区分。

同一条时间线内保留建筑、道路、族群谱系与组织继承；发生代际推演时交代成员接替、修缮、遗址和用途变化。不同起点共用河谷布局有利于比较，但不能把不同物种、气候与人口的世界宣称为只有材料不同的严格对照。

主世界资产和实验副本继续隔离：跨世界发货使用唯一物品与数量，实验复制品不能回流兑现。第一期仅一个世界详细运行，其他世界明确暂停；远区/离线推进后续单独验收。

## 4. 各时代的内容差异

以下是原创的虚构场景模板，不声称复原所有地区的真实社会发展路径。

|时代包|可见生命/人物|代表性组织或群体|材料可以推动的具体项目|玩家看见的变化|
|---|---|---|---|---|
|早期微生物湿地|氧敏感/耐氧的教学微生物群落|菌毯群落，无人类组织|局部供氧、补水、改变遮光/可用养分|菌毯范围变化，不同条件下的群落占比改变|
|古生物河谷（后续独立包）|植物、草食动物、捕食者|群居与繁殖群体|蓄水池、栖地桥、遮荫与食物供给|觅食/迁徙路线变化，跨代性状分布改变|
|古代河谷聚落|农户、陶工、渔民、长者、学徒|家户、作坊、商队、村社|储水容器、灌溉、工具、保温屋和桥|居民搬料施工、少走取水路、工坊和田地布局变化|
|近代工业聚落|工人、技师、商人、医生|工厂、商会、工人互助组织、市政|供热、抽水、运输、除尘、通信|管线/烟尘/作息变化，住房与河岸用途竞争|
|现代聚落|居民、工程师、研究人员、维护员|企业、实验室、公共服务机构、社区|光伏、储能、冷却、水处理与材料回收|夜间供电、设备停机/恢复、耗材补给与回收路线|
|未来栖居地|人类、服务机器人；其他生命后续决定|栖居委员会、科研联合体、资源运营方|封闭循环、再生材料、自维护设备|维修机器人活动、损坏部件替换、资源在系统中循环|

动物并不在进入人类时代后退出：农田和工厂仍与栖地争用水、土地与食物，现代居民仍需要适宜温度与环境。军需可作为未来新增的资源用途/组织项目，第一批不扩成战术战争系统。

## 5. 新材料如何影响生命：一条可以解释的因果链

材料身份/相态/加工状态 → 可核对性质 → 投放方式、数量和位置 → 当地环境或设备能力 → 生物/人物行动 → 生产、繁殖、迁移和组织变化。

初期限定四种作用通道：

1. **环境供给与暴露**：补水、供氧、营养；记录供给量、介质、暴露时间及目标群体。生命响应由需要和耐受决定。
2. **栖地结构**：围栏、遮荫、桥、池岸改变光照、通行、饮水点和繁殖场所。材料先影响构件耐用/适用性，再影响栖地。
3. **器件服务**：导线、散热芯、滤材等经加工进入供电/冷却/水处理装置。持续效果受供能、通量、耗材和维护约束。
4. **生产与分配**：材料进入工具、容器、交通或加工设备；不同组织决定先给谁用，引发就业、搬迁、贸易和研究需求。

不能给材料一个对所有生命通用的“毒性分数”。需要匹配材料形态、释放/溶解、介质、剂量和暴露时间；无法验证的具体生物效应保持未知。

### 科学依据与教学边界

- 早期氧增多对不耐氧微生物不利 [S1]，水生动物对溶氧有需求 [S2]。游戏中必须按群落判定，不能用“史前时代”标签让所有生物怕氧，也不能把大气氧含量直接当水中溶氧。
- 营养输入可经过藻类增长、遮光、残体分解耗氧形成延迟后果 [S3]。应能看见过程，并允许控源、收割、处理和供氧等不同干预；加营养并不必然立即杀死动物。
- 遗传变异与差异化的生存/繁殖会改变群体性状 [S4]。短时间先呈现行为与健康变化；多代后才呈现遗传性状分布改变，不让“喝了新材料”即时变成新物种。体色等外观变化只有与该遗传机制相关时才改变。
- 净水处理针对不同目标，并有容量、维护、浓缩/废料等约束 [S5]。颗粒减少不等于去盐、去病原体或饮用安全；滤材也不能只因“多孔”就获得万能净化能力。

这些来源支持定性方向，不提供本游戏动物的真实致死阈值，也不证明任意玩家材料的性能。图鉴区分参考事实、模型估计、教学规则和未来科幻设定。

## 6. 用途由能力与配方判定

复用现有材料证据档案/工坊库存。结构样品、工业材料、器件分层；已有铜铝分层模型的结果仅在其适用条件和用途内使用。

每条用途声明所需属性、形态、条件和制成步骤；每项证据有来源、范围和版本。候选材料通过用途筛选后再加工为可安装部件。未知项不当零，等待科研计时本身不能变出实测值。家族内估计要有适用域/验证；跨体系统一线性插值不是默认方案。

样品研究、艺术展示和隔离假设实验继续给未知作品用途。以后逐个加入有证据的热学、电学、结构或处理家族，避免为每个分子×每个时代单写效果表。

科技能力分成三层：

- **会使用**：有人理解操作，具备所需输入和连接。
- **能维护**：有人排故，有耗材、替换件和工具。
- **能制造**：掌握工艺，并有当地生产设备、能源和原料。

例如玩家可在古代聚落安装一套来自浮岛的太阳能泵。村民经过教学后使用它；缺备件时仍可能依赖浮岛。只有本地加工链建立后才具备复制能力。材料赠送不直接给全社会加“文明等级”，也不禁止古代居民接触先进器件。

## 7. 组织和人物怎样产生变化

组织先共用生产、流通、研究、公共事务四种职责模板，每个实例保存成员、共享库存、掌握工艺、当前需求、资源分配偏好和少量关系。时代包更换其组合、名称、制度与外观。

项目流程：发现短缺 → 提出用途需求 → 根据库存/工艺/维护能力选择方案 → 预留物资和人员 → 运料施工 → 运行维护 → 记录成效 → 调整下一项目。房屋/机器真正出现，人员实际到场，避免项目只在面板进度条完成。

人物首期两项突出性格、两项技能、一项当前愿望，以及少量重要关系/记忆。可选性格轴：好奇/谨慎、勤勉/散漫、合作/自利。角色与性格分开，工程师不自动勤勉，商人不自动自利。

性格改变行动权重而不直接改变物理规律：好奇者愿意参加新材料试用，谨慎者偏爱小规模验证，勤勉者优先维护，合作型会分享方法；严重缺粮等紧迫需求仍会影响选择。已经证明有效的材料不因一次无理由随机判定而变无效。

记忆要有来源：某供水器曾断供，某村民修好了它，某组织分享了备件。这些经历影响以后信任和采购。把记忆筛成少量关键项并合并重复事件，避免两两人物关系与无限日志膨胀。

叙事调度只挑选有真实条件的请求/事件并控制节奏，不暗中改写物料或制造无因损失；天气等外生事件保留种子和来源。事件文本可模板化，核心决策不依赖在线大模型。

## 8. 三个可制作的故事

**氧气在两个世界中的不同后果。**同一浮岛供氧补给进入氧敏感菌毯与缺氧鱼池，前者适生范围减小、后者缺氧压力缓解。玩家走近能看见群落覆盖或鱼的聚集/活动变化。这个差异由生物与暴露条件产生，不能写成所有史前生命都受伤。补给不会无限供氧；作为两个不同群落案例，不声称严格单变量实验。

**同一材料被不同人用在不同地方。**一种已验证为低渗透且在指定条件下耐用的陶瓷构件：古代居民考虑储水和灌溉容器，近代组织考虑相应工况的容器/衬件，现代实验室可能提出更严格的处理组件要求。后两种用途需分别通过条件验收，材料没有因换时代而自动合格。爱尝试的陶工想试新容器，谨慎的长者先为部分农户试用，商队提出可运输规格。出现的故事来自真实项目选择。

**古代聚落的先进泵。**玩家安装有限功率的成套水泵并带来说明，农户开始灌溉，另一户关心下游剩余水量；器件损坏后，有人要求继续进口，有人要求培训本地维修。玩家可送更多成品，或投入工具与研究，建立当地能力。后续现代起点复用同样的取水、供能、维护与分配规则，组织形式和技术选择更丰富。

故事结尾可带回真实样本、项目纪念物或微缩作品。作品记录使用的材料与经历；重复复制蓝图不复制产能、物资和稀有奖励。

## 9. 呈现与模型预算

世界变化优先使用位置、行动与外形表达：缺水者走去取水；新容器安装后取水路线改变；设备耗材空了会停机；工人到场维修；组织旗帜/工服标明归属；居民围观试用、搬家或改建。点选对象可展开“发生了什么、原因是什么、接下来需要什么”。

时间线用实景缩略图和因果节点记录关键干预；日常时间不突然把建筑换成下一时代模型。长期推演呈现同机位的施工、修缮、遗址和成员接替。没有发生的事件不能为了年鉴热闹而补写。

人体共用骨架和基础搬运/工作/交谈动作，以服装、工具和少量姿态区分时代。设备按取水/储存/处理/供能/运输等功能复用交互，外壳和工艺区分年代。每个时代仍需要少量辨识度高的轮廓/标志物，避免只换名字与颜色。

以下是需要压测的初始上限，不是已实现性能：

|维度|首个完整切片预算|
|---|---|
|地理|保留现有河谷，必要时扩至128×128米验证；256×256米仅作后续候选，不强制扩图|
|详细运行世界|1个；其余明确暂停|
|时代内容|2个起点：早期微生物湿地、古代河谷聚落；其他先定义内容包接口|
|附近详细实体|最多约36个，包括最多12名可追踪居民；额外生态用群体摘要，呈现方式明确|
|活跃组织|每个聚落先2个，组织并行项目总量先3个|
|环境通道|水量/湿度、温度、光照、溶氧、营养与颗粒/有机负荷先限定用途；其他通道按故事需要增加|
|更新|生态1Hz、组织项目约每5秒错峰评估、人物行走渲染插值；交互即时响应|
|模型|首期约6种可组合建筑/设备功能骨架，植物/动物模板复用现有；时代专属地标每包先1—2个|
|性能目标|Android 30FPS、桌面/Web 60FPS分别验收，包含长时间运行/温升/保存；当前桌面短测不作手机结论|

按需生成只解决未探索地形的存储；开采、建造、对象与群体状态仍需记录。存档保存生成器版本与差量，返回不会刷出已经挖掉的矿。一个大网格不包住全世界；破坏只更新相关区块。未知世界数量可以增长，内容制作与活跃模拟数不成倍增长。

## 10. 接入现有工程

当前已有材料身份证据、工坊配方/真实库存、旧时代试验台、河湾生态及第一人称显示。优先复用数据和模型，不将旧时代面板直接堆进新世界。

建议新增边界：时代起点配置、用途资格解析、位置化世界对象、局部环境、居民需求与项目、组织、人物性格记忆、因果事件与时间线存储。每个模块通过明确命令/事件连接；钱包、物流与保存仍有唯一协调入口。

内容包定义initial_state、species、known_processes、institution_templates、visual_kit和available_story_templates；不得定义“本时代所有氧气有害”这类覆盖物理/生态层的全局特例。固定时间步、种子和配置版本让对照可复现。

后续切片顺序：

1. **先完成手边交互**：对象选择、快捷栏、落点放置、真实取水/种植/喂食/回收，接上回程与微缩蓝图基础。
2. **一个材料、两种生物响应**：局部供氧/有限补给、来源批次、可见行动与因果回看；再加营养的延迟效应。
3. **古代聚落与两种组织**：少量居民能提出需求、搬料、施工和维护；同一材料因工艺/项目不同被选择或拒绝。
4. **性格与知识传播**：先让两名性格不同的角色对同一试用提出不同方案，再补记忆、教学、组织采纳和备件需求。
5. **复用到近现代与未来**：只有前四步可玩、数值稳定、手机版成本可接受时才增加内容包；地下洞穴、完整军政和无尽生成分开排期。

## 11. 验收问题

- 隐去时代名称后，玩家能否从物种、外形、工艺、组织行为辨认差异？
- 同一材料同条件下的性质是否一致？生物响应是否来自群落和暴露，而非时代硬编码？
- 同一对象能否通过第一人称与上帝视角执行同一库存事务，取消/重载不复制？
- 玩家能否看见“材料/设备 → 局部改变 → 谁采取了行动”，而不读长篇数值？
- 材料好处、代价和未知项是否清晰，是否存在不用最新材料也能维持的方案？
- NPC不能生产先进件时，是否说明缺知识、设备、原料或能源，而非只显示“等级不够”？
- 不同性格是否改变实际行为？是否仍受真实库存、需求和可达性约束？
- 开采、动物身份/谱系、建筑和停机状态在离开/加载后能否正确保持？
- 30分钟游玩、扩图、换时代和存档增长是否在手机预算内？没有真机时保持待验证。
