# 0.3.0 · 元素仓库

## 本版怎么玩

1. 从左侧打开“元素仓库”，购买1份或5份元素；确认前显示总价、现有库存与钱包。这里只使用游戏金币。
2. 新开局或首次升级到0.3时获得H×2、O×1、S×1、Cl×2。后续载入不重复赠送。
3. 选择反应炉进入原子工作台，点一个原子或底部位点按钮，再点“替换这个位点的元素”。选择新元素只更新草稿和产率预览。
4. 水的O换S，识别为H₂S；H₂中的一个H换Cl，识别为HCl。氢/氯的两个位置互换仍可识别。
5. 钙钛矿选择一个Br，再开启“整组替换”，把6个Br显示位点全部换成Cl，识别为教学CsPbCl₃。它消耗6份Cl，晶胞的实际计量仍为Cs:Pb:Cl=1:1:3。
6. 替换保留当前坐标，可继续拖动调整；应用后按新结构的参考几何生产。收获产物后解锁新图鉴卡，新增收购商会在原四单之后依次出现。

## 费用与事务

- 购买单价：H 2、O 5、C 6、S 9、Cl 8、Br 12、Cs 18、Pb 20金币/份。这些是游戏平衡参数。
- 每个最终改变的显示位点消耗1份目标元素；同一草稿中反复尝试只按最终结果计算。拆下的元素不返还。
- 每次确认一批修改仍为`12×炉等级²`金币，同时修改元素和坐标只收一次编辑费。同等级价格不递增。
- 取消、预览、撤销全部、最终无变化都不收费。金币不足、元素不足、无效坐标或未知元素符号时整批失败，资源和原结构保持不变。
- 应用成功清空该炉旧库存、待收金币、生产进度与待结算建材批次；界面持续显示提醒。
- 新增三个结构不能直接从模板菜单免费装载，也不能通过直接建炉绕过替换所需原料。

## 已知参考与探索样品

识别限定在继承的结构族与位点组成：双原子、弯曲三原子、四面体、钙钛矿ABX₃。它不是任意化学结构识别器，更没有求解化学反应或电子结构。

没有适用参考的组合显示“探索组合 / 匹配度未知”。连线仅保留原来的编辑骨架，球体尺寸仅作展示，不指定未知组合的价态和配位。探索样品固定获得0.15金币/秒，不随等级或复杂度增加，不生产可售产物或建材，不参与科研订单。恢复为有参考的组成后恢复正常生产。

当前共有8种元素、7种结构。氯在HCl中使用共价半径1.02 Å，在CsPbCl₃教学胞中使用Cl⁻、CN6的有效离子半径1.81 Å。来源和模型边界见[科学说明](SCIENCE-V0.3.md)。本版没有真实势函数或DFT。
